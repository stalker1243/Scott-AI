# Перенос из Avalonia в Qt

Состояние на 6 октября 2026 года. Переносим по одному разделу: интерфейс,
реальные запросы к backend, ошибки и проверки, затем следующий раздел.

## Уже доступно

| Раздел Qt | Что есть | Что ещё переносить |
|---|---|---|
| Обзор | Состояние Scott, ресурсы компьютера, быстрый переход к диалогу | Остальные действия главной страницы |
| Диалог | Сохранённые чаты, история, переименование, очистка, фото, документы, видео, генерация, режим действий | Форматирование ответов, редактирование изображений |
| Модели | Каталог, API Token, свой ID, проверка подключения, возможности выбранной модели | Дополнительные параметры по мере необходимости |
| Память | Категории, поиск, добавление, подтверждение удаления | Массовые операции |
| Система | Нагрузка CPU/RAM/GPU/диска, запуск и подключение | Остальные сведения о компьютере |
| Настройки | Голос, звук, устройства обработки, трей | Остальные параметры исходного лаунчера |
| Внешний вид | Темы, три стиля, акцент, значок, анимации, прозрачность окна | Новые стили по мере необходимости |
| Профиль | Имя, «о себе», характер ответов, интересы, фото и кадрирование | — |
| Действия | Возможности Scott, доступность, поиск, категории и примеры в диалог | — |
| Протоколы | Редактор шагов, паузы, повторы, голос, расписание, копии, импорт/экспорт, запуск и остановка | Условия и параметры сценария — следующий этап расширения |

## Следующие разделы

| Порядок | Исходная страница | Назначение |
|---|---|---|
| 1 | LogsView, DiagnosticsView | Журнал и диагностика |
| 2 | AnalyticsView | Статистика работы |
| 3 | AboutView | Версия приложения и сведения о проекте |
| 4 | RemoteView, HologramView | Дополнительные способы взаимодействия |

ProjectsView оставлен на последующий этап по прежней просьбе пользователя.
Исходники находятся в `../ScottAI_avalonia/Views/`, логика — в соседних ViewModels.
Порядок можно изменить по следующей задаче пользователя.

## Навигация

Обзор, Диалог, Действия, Протоколы, Память, Модели, Система и Профиль расположены сверху. Оформление и
Настройки закреплены внизу. При переносе автоматизации можно
добавить отдельную группу; новые пункты появляются вместе с рабочей страницей.
Существующие индексы страниц сохраняем, чтобы переходы и HTTP-загрузка
продолжали обращаться к нужным разделам.
