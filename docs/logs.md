# Логи и архив диагностики

В текущих исходниках после 2.0.1 есть вкладка **Логи**: выберите журнал,
нажмите **Обновить** или **Собрать архив**. Backend для этого не требуется.
На экране первой подготовки также есть кнопка **Логи**.
Место сохранения ZIP выбирает пользователь; автоматической отправки нет.

Архив включает сведения об ОС, Python, версиях библиотек, свободном месте
и драйвере NVIDIA, а также журналы Qt, процесса backend, первой подготовки,
установки Scott Voice, подготовки браузера и Linux-установщика. Для браузера
выберите `browser-setup.log`: в нём видны проверка библиотек, их установка
и подготовка Chromium. Чтение ограничено последними 2 МиБ каждого журнала;
журналы Qt, подготовки, браузера и Scott Voice имеют ограниченную ротацию.

API Token маскируются по известным форматам и сохранённым значениям.
`.env`, настройки моделей, история, вложения и журналы исполнения команд
не включаются. Журналы технических ошибок могут содержать названия файлов
и сообщения библиотек; архив можно просмотреть перед отправкой.

Папка журналов:

- Windows: `%LOCALAPPDATA%\ScottAI\logs`.
- Linux: `${XDG_STATE_HOME:-~/.local/state}/ScottAI/logs`.
- Для отдельной проверки можно задать `SCOTT_LOG_DIR`.

На Linux в текущих исходниках ошибки backend, журналы исполнения и измерения
времени также используют этот каталог. `EXECUTE_LOG_DIR` и `TIMING_LOG_DIR`
могут задать отдельные пути. Пустой или относительный `XDG_STATE_HOME`
заменяется на `~/.local/state`. Архив API без заданного места сохранения
создаётся в `~/.local/state/ScottAI/reports` либо соответствующем абсолютном
XDG-каталоге. Рабочая история установленного Linux-пакета в текущих исходниках
находится в отдельном [хранилище пользователя](linux.md#xdg-каталоги-в-текущих-исходниках).
Токены маскируются как из прежних, так и из новых настроек и `.env`;
сами файлы настроек и переписка в архив не включаются. Старые технические
журналы в папке программы по-прежнему доступны для диагностики.

Если интерфейс не открывается, сборщик работает через Python из установки:

```powershell
.\runtime\python.exe .\backend\diagnostics.py --json --output .\scott-support.zip
```

```bash
./runtime/bin/python ./backend/diagnostics.py --json --output ./scott-support.zip
```

Запускайте эти команды из папки установленного приложения. Если Python
повреждён, сохраните имеющиеся журналы из указанной выше папки.
