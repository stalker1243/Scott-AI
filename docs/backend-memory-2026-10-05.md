# Долговременная память: проверка 5 октября 2026

## Причины забывания

История диалога сохраняла только шесть сообщений. Более ранние завершённые
пары перезаписывались. Часть локальных ответов и голосовых команд оставалась
в отдельной истории, которую модель не использовала. В добавку к запросу
попадали самые новые факты, поэтому старое важное сведение могло не попасть
даже при наличии записи на диске.

## Изменения

- Постоянный архив завершённых пар и локальный индекс поиска в SQLite.
  При запуске переносятся обе старые JSONL-истории; исходные файлы сохраняются.
- Контекст последних 20 сообщений с ограничением размера и подборкой
  подходящих старых разговоров. Архив не обрезается вместе с контекстом.
- Общая запись для чата, локальных ответов и голосовых команд. Неизвестные
  разговорные фразы используют настроенного ассистента с памятью.
- Автоматическое сохранение явных сведений из слов пользователя. Имя,
  сведения о том же проекте и стиль ответа обновляются при уточнении.
  Основные сведения имеют приоритет при заполнении списка.
- Старые факты выбираются по теме вопроса. Имя и стиль ответа доступны
  также из записей прежнего формата без служебного ключа.
- Простые вопросы об имени и месте проживания отвечаются локально.
- В Qt: отметка «Из диалога», переключатель автозапоминания, счётчик истории
  и отдельная очистка диалогов. Удалённые факты исключаются из подбора
  соответствующих исходных реплик в контекст.
- Ошибка архива сохраняет запасной путь через последние сообщения.
  Сбой очистки JSONL откатывает очистку SQLite. После временной ошибки записи
  последние сообщения сверяются с архивом при следующем запуске.

## Ограничения

Автоматическое извлечение распознаёт явные формулировки ограниченного набора.
Поиск истории работает по словам и формам слов; поиск по смыслу ещё не добавлен.
Старые диалоги, которых уже нет в сохранившихся файлах, восстановить нельзя.
Длинные прошлые сообщения сокращаются в запросе, полный текст остаётся в архиве.
Большой текущий вопрос может превышать бюджет контекста.

Использование и управление: [memory.md](memory.md).
