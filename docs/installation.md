# Первая подготовка и размер приложения

Начиная с 2.0.1 мастер подготовки поддерживает продолжение загрузки моделей,
проверку целостности и компактную CPU-установку.

## Подготовлено после 2.1.1

Крупные веса Scott Voice загружаются с сохранением полученной части между
повторами установки. На экране показывается объём текущего файла в МиБ;
перед использованием проверяется официальный SHA256 закреплённой версии.
Готовые Python, библиотеки и совместимое ускорение основной среды используются
повторно. При отказе сервера в доступе установка сообщает об этом отдельно.

Статус pip переходит к распаковке после сообщения самого установщика пакетов.
Общий размер его временной папки больше не выдаётся за процент скачивания.
Журналы сохраняют версии и размеры пакетов при включённых служебных флагах SDK;
настоящие токены и ключи продолжают скрываться.

В исходниках подготовка Windows и компактного Linux сохраняет отдельный кеш
Python-библиотек при ошибке установки. Повторная попытка может использовать
полностью полученные файлы. Незавершённый wheel может потребовать новой загрузки.
После каждого шага pip кеш сокращается до 256 МиБ, после успешной установки
библиотек его файлы очищаются. Глобальный кеш pip пользователя не меняется.
Во время активной передачи размер кеша может временно быть больше этого лимита.
Большой PyTorch использует прежнюю загрузку частями с проверкой SHA256.
При недостающих моделях готовые библиотеки проверяются один раз, без повторного
импорта Torch в ещё одном процессе перед продолжением подготовки.
В полном Linux-профиле кеш pip по-прежнему отключён из-за крупных зависимостей;
компактный профиль без Torch/Triton использует ограниченный кеш своей среды.

Отдельная установка Scott Voice на Windows теперь тоже сохраняет полностью
скачанные пакеты при ошибке или отмене. Её кеш находится внутри папки Scott Voice;
после остановки каждого шага pip он сокращается до 256 МиБ. После успешной
проверки библиотек кеш очищается перед загрузкой модели. При недоступном кеше
установка продолжается без него, сохраняя чужие файлы. Это уменьшает повторные
скачивания при сбоях; размер модели и скорость синтеза речи остаются прежними.

Эти правки ещё не включены в опубликованный установщик 2.1.1.

### Режим подготовки

В мастере доступны **Автоматически** и **Обычный CPU**. Автоматический режим
подбирает ускорение по оборудованию; CPU использует процессор. Уже сохранённые
настройки распознавания и профили прежних установок поддерживаются.

Выбор хранится в `runtime_profile.json`. Отмена не сбрасывает его, повторная
подготовка продолжает тот же режим. Параметры модели, история и голос из-за
изменения интерфейса не переписываются. Scott Voice готовится отдельно.

### Запуск после подготовки

Мастер теперь остаётся на этапе «Подключаем backend…», пока backend не ответит
на проверку готовности. Если запуск не удался после успешной подготовки,
«Повторить запуск» подключает backend без повторного скачивания библиотек.

На главном экране можно установить Scott Voice, увидеть ход подготовки,
отменить её и затем запустить микрофон. После явного включения микрофона
установленная модель голоса готовится в фоне; сама подготовка не включает
микрофон. На системах без поддержки Scott Voice распознавание команд и чат
остаются доступны. [Поведение при сбоях](reliability.md).

Они уменьшают повторные загрузки при сбоях. Первая установка по-прежнему получает
библиотеки и веса из сети: например, закреплённый CUDA-wheel PyTorch для Windows
занимает 2 602 769 784 байта. Время зависит от скорости источника, соединения
и распаковки. При 1 МиБ/с передача одного этого файла заняла бы около 41 минуты.

Поведение кеша pip описано в [официальной документации](https://pip.pypa.io/en/stable/topics/caching/).

В исходниках добавлены длительности этапов подготовки и Scott Voice.
При долгой установке соберите архив вкладки «Логи»: в нём сохраняются журнал
подготовки и части `timings.jsonl`. По ним можно отличить проверку среды,
получение PyTorch, pip и модели. [Как прочитать замеры](performance.md#собрать-сведения-о-проблеме).

## Исправления в 2.1.0

### Продолжение загрузки PyTorch

Для штатного Python 3.13 x64 на Windows/Linux CPU- и CUDA-wheel загружаются
до четырёх потоков с сохранением завершённых частей. Перед установкой
проверяется полная SHA256 закреплённого файла. Если сервер не поддерживает
диапазоны, используется обычная проверяемая загрузка. Прокси и скорость
соединения по-прежнему влияют на время подготовки.

После успешной установки скачанный wheel удаляется из служебного кеша.
При прерывании он сохраняется для продолжения. Другие Python-пакеты
по-прежнему устанавливает pip. Это не уменьшает размер распакованного PyTorch.

### Отдельное окно обновления

Лаунчер проверяет новые выпуски без участия backend. Когда версия доступна,
появляется кнопка «Обновить»; ручная проверка находится в настройках, в разделе
«Прочее». После нажатия запускается отдельное окно 480×260, затем закрывается
основной лаунчер. Если окно обновления не запустилось, Scott остаётся открыт.

В окне видны процент и объём скачивания, проверка SHA256 и установка.
При обрыве можно продолжить загрузку; скачанные части сохраняются и после
повторного запуска обновления. При ошибке доступны «Повторить» и «Открыть Scott».
Отмена или закрытие окна во время скачивания возвращают в приложение.
Во время установки окно остаётся открытым; после успеха Scott запускается снова.

В Windows используется штатный установщик без дополнительного мастера, в Linux
— установщик проверенного tar.gz-пакета. История, настройки, окружения и модели
сохраняются по правилам установщика. Прогресс установки показывается как этап,
процент относится к загрузке. Если для выпуска нет проверенного пакета или
лаунчер запущен из исходников, предлагается страница выпуска.
Для AppImage в доступной папке пользователя окно заменяет сам файл образа,
сохраняет прежний рядом как `.scott-previous-….AppImage` и перезапускает приложение.
Режим FUSE или распаковки сохраняется. Временная папка AppImage не обновляется
установщиком tar.gz. При ручной распаковке или отсутствии прав предлагается
страница выпуска; пользовательские данные и Python хранятся отдельно.
Эти изменения включены в 2.1.0.

Для замены файлов окно использует собственную копию Qt в пользовательском кеше;
старый процесс завершается до установки. `updater.log` входит в архив диагностики.

Qt собирается как оконное приложение Windows. Backend, подготовка библиотек
и диагностика запускаются в фоне. В мастере видны прошедшее время,
остановка, повтор и сбор архива логов; готовый профиль PyTorch при повторе
сохраняется. Если pip поддерживает продолжение оборванной передачи, оно
включается автоматически. Это не уменьшает объём GPU-библиотек и не ускоряет
само интернет-соединение.

Для AMD RX 400/500, включая RX 580, автоматическая подготовка выбирает CPU:
текущий профиль ROCm не рассчитан на эти карты. Whisper `small` сохраняется.

Scott Voice проверяет ответ драйвера NVIDIA до больших загрузок. Установка
сохраняет журнал, ограничивает время каждого шага, продолжает загрузку Python
и пропускает уже готовые библиотеки и проверенные файлы модели при повторе.
Ответ драйвера не гарантирует работоспособность CUDA: после загрузки выполняется
проверка окружения. Scott Voice остаётся необязательным Windows/NVIDIA-движком.

Эти изменения включены в установщик 2.1.0.
Сбор диагностики описан в [документации логов](logs.md).

## Чат и голос

В исходниках после 2.1.1 первая подготовка устанавливает библиотеки и выбранную
модель Whisper (`small`, если выбор не меняли). Silero и зависимости прежних
голосов больше не скачиваются. Размер зависит от модели, платформы и PyTorch.
Единственный голос — Scott Voice; его компонент готовится отдельно в настройках.
Пока подтверждена установка Windows x64/NVIDIA CUDA. На Linux/AMD доступен чат
и поддерживаемое распознавание, без обещания работающего синтеза Scott Voice.
В опубликованном 2.1.1 ещё действует прежний каталог голосов.

### Отдельные компоненты

- **Scott Voice** — отдельное окружение и модель, подготовка в настройках голоса.
  Рабочие скрипты обновляются штатным установщиком; готовые библиотеки и
  проверенные веса повторно используются. Без этого компонента чат и
  распознавание работают, озвучка недоступна. Подробнее — [Scott Voice](voice.md).
- **Управление браузером** — подготовка в панели браузера. Playwright ставится
  отдельно от основной среды; при наличии системного Edge/Chrome/Chromium
  второй браузер не скачивается. После прерывания готовые библиотеки
  проверяются независимо от итоговой отметки установки. Подробнее —
  [продолжение подготовки браузера](browser-control.md#если-подготовка-прервалась).

Для подготовки на процессоре выберите **Обычный CPU**. Без подходящего
ускорителя автоматический режим тоже использует закреплённую CPU-сборку
PyTorch. Отдельный компонент Scott Voice пока требует NVIDIA CUDA.

Мастер открывается отдельным окном. Пока идёт проверка или загрузка,
основной интерфейс скрыт; кнопки трея возвращают к подготовке.
После успешного завершения появляется приложение. Закрытие мастера
останавливает подготовку и завершает лаунчер.

## Обрыв загрузки или ошибка SHA256

- Нажмите **«Повторить»**. Уже установленные библиотеки проверяются и повторно
  не устанавливаются, если соответствуют требованиям и выбранной CPU/GPU-сборке.
- Модель скачивается в файл `.part`. После остановки или обрыва загрузка
  продолжается с сохранённого места, если сервер поддерживает HTTP Range.
  Если сервер отдаёт полный файл, мастер явно сообщает о начале заново.
- Whisper используется только после совпадения полной SHA256 с суммой
  из установленной библиотеки Whisper. Повреждённая загрузка повторяется
  автоматически, максимум три попытки при сбоях. Проверка целостности сохраняется.
- Кнопка **«Остановить»** прекращает подготовку; уже скачанная часть модели
  остаётся. Для закреплённых CPU/CUDA-wheel PyTorch также сохраняются части;
  загрузку остальных Python-пакетов контролирует pip.

Для сетевых операций заданы таймауты; установка пакетов и подготовка моделей
также имеют общий предел ожидания. Мастер показывает скачанный объём и размер
файла, когда сервер сообщает его. Скорость зависит от соединения и сервера.
Whisper `small` с официального сервера занимает 483 617 219 байт, около 461 МиБ.

Загрузка первой подготовки не открывает микрофон, не исполняет команды
и не запускает распознавание или озвучку. Whisper проверяется по файлу без
загрузки весов на видеокарту. Статус этой подготовки означает готовность
распознавания; готовность Scott Voice показывается отдельно в настройках голоса.
В текущих исходниках после 2.0.1 подготовка учитывает `WHISPER_ENGINE`:
`auto`/`faster` готовят faster-whisper, если его библиотека доступна; HIP на
AMD GPU и `openai` используют обычный Whisper. Модель и выбор движка сохранены.
Для faster-whisper проверяются все необходимые файлы, включая токенизатор,
по официальным хешам закреплённой версии. Готовый кеш работает без повторного
запроса списка файлов. При аппаратном сбое faster-whisper обычный Whisper
остаётся резервом; его `.pt` загружается только при необходимости.

Обычный запуск теперь показывает компактное окно «Запускаем ScottAI».
Большое окно подготовки появляется, когда действительно нужны библиотеки
или модели. Главное окно остаётся скрытым до готовности.

## Что занимает место

Основной размер установленного приложения дают Python-зависимости и веса
моделей. Размер установщика и размер после подготовки — разные величины.
GPU-сборки занимают больше места; Scott Voice добавляет отдельное окружение
и веса. Удаление истории или вложений не требуется для уменьшения базового пакета.

В проверенном Windows CPU-окружении Python и библиотеки занимают
1 315 521 939 байт (1,23 ГиБ). Вместе с базовым пакетом, Whisper `small`
и Silero получается ориентировочно **1,8 ГиБ**. Это расчёт по измеренным
компонентам, а не замер новой установки целиком; вложения и отдельный Scott
Voice добавляют место. В текущей подготовке faster-whisper лишний `.pt` не
скачивается: экономия около 461 МиБ против загрузки обоих форматов `small`.
Уже существующие модели пользователя не удаляются. Проверенный пакет
faster-whisper `small` занимает 486 212 372 байта (около 464 МиБ).

В отдельном новом кеше Windows загрузка этих четырёх файлов заняла 202 с,
проверка без запроса к серверу — 0,42 с; модель загрузилась на CPU без
интернета. Это проверка модели, не время полной установки и не обещание
такой скорости на другом соединении.

Настоящая первая подготовка отдельного Windows-пакета со встроенным Python
3.13.7 и CPU прошла за 9 мин. 53 с; повторная проверка подтвердила готовность.
Приложение с библиотеками и кешем речи заняло **около 1,82 ГиБ**.
Проверялись `small`, faster-whisper и Silero. В этот размер не входят
необязательные Scott Voice/браузер, модель семантической памяти и личные
данные. GPU-профиль крупнее; время зависит от соединения, сервера и распаковки.

Дополнительный замер 15 октября на Windows: отдельное окружение Scott Voice
занимало **4,70 ГиБ**, включая **3,86 ГиБ PyTorch/CUDA**, а его веса — ещё
**2,34 ГиБ**. Всего около **7,05 ГиБ дополнительно**, без временных загрузок
и пользовательского аудиокеша. Библиотеки управления браузером — около
106 МиБ, отдельный Chromium при необходимости добавляет место. Это размеры
файлов в проверенном окружении, а не гарантированный размер каждой установки.
Scott Voice и браузер не входят в приведённые выше 1,82 ГиБ базового режима.

### Размер перед подготовкой

Мастер показывает оценку размера для обычной и компактной установки.
Для стандартного `small` ориентир на Windows — **около 2 ГиБ на CPU**,
на Linux x86-64 — **3–4 ГиБ на CPU**, на NVIDIA/CUDA — **5–7 ГиБ**.
На время загрузки и распаковки нужны примерно 2,5 ГиБ для Windows CPU,
4,5 ГиБ для Linux CPU и 9 ГиБ для GPU
свободного места соответственно. Более крупные модели, пользовательские файлы
и дополнительные компоненты требуют отдельного места. Перед новой подготовкой
проверяется свободное место, включая отдельный диск временных файлов.
К повторной проверке готовой установки полный резерв не применяется.

Для **нового Scott Voice** установщик повторно использует совместимое ускорение
основного приложения, если оно уже готово. Ориентир дополнительного размера —
**3–4 ГиБ**, для подготовки оставьте 5 ГиБ свободно. При несовместимом основном
окружении используется самостоятельная установка — около 7–8 ГиБ, с резервом
10 ГиБ. В настройках показан подходящий вариант; окончательную совместимость
проверяет установщик. Существующие самостоятельные окружения сохраняются.

В изолированной Windows-проверке новое окружение и прежние проверенные веса
заняли **2,69 ГиБ дополнительно** при готовом CUDA-окружении приложения.
Контрольная реплика совпала с прежним WAV побайтово. Это экономия диска;
генерация речи по-прежнему может быть медленнее её звучания. Если обновление
основной установки меняет совместимость, нажмите **«Обновить Scott Voice»**.
Веса и принятый эталон сохраняются при восстановлении.

Подготовка больше не сохраняет вторую копию скачанных Python-пакетов в
общем кеше pip. Существующий кеш не удаляется. Windows-установщик резервирует
2,5 ГиБ сверх базового пакета для компактной подготовки и распаковки,
вместо прежних обязательных 5 ГиБ. GPU-библиотеки требуют больше места.

В упаковке текущих исходников убраны неиспользуемые стили Qt Quick Controls.
Приложение использует Qt-стиль Basic; оформления Classic, Glass и Terminal Pro
реализованы самим Scott и сохранены. Программный OpenGL и библиотеки для трея
также сохранены. Все 47 файлов сведений о компонентах и лицензиях Qt сохранены
без изменения содержимого в `licenses/qt-sbom.zip`.

В проверочной Windows-сборке базовый пакет на диске уменьшился с
184 435 734 до 129 153 336 байт (176 → 123 МиБ, около 30%).
Сжатый установщик уменьшился значительно меньше: Inno Setup уже сжимал
текстовые сведения Qt. Это измерение базового пакета без установленных
Python-зависимостей и моделей.

Готовность проверяется по составу библиотек и файлам моделей. Наличие
`small.pt` или папки Silero само по себе не означает, что подготовка завершена.
История, API Token, вложения и пользовательские настройки при повторе сохраняются.
