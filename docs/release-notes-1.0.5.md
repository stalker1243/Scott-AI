# Scott AI 1.0.5

## Что починено

**Обновление поверх работающей программы.** Установщик упирался в занятые
файлы: «Не удалось автоматически закрыть все приложения» и предложение
проигнорировать ошибку. Окно лаунчера Windows закрыть умеет, а вот backend —
нет: это Python без окна, и закрывать его было некому. Теперь установщик гасит
их сам, причём Python — только тот, что запущен из папки Scott: чужие процессы
не трогаются.

**Лаунчер называется ScottAI.** Раньше файл и процесс носили имя
`ScottAI.Avalonia` — по названию библиотеки, которую человек не выбирал. Оно
попадалось на глаза в диспетчере задач и в том самом окне про занятые файлы.
Старый файл при обновлении удаляется, чтобы в папке не осталось двух программ.

## Обновление

Скачайте установщик и запустите поверх — теперь можно не закрывать Scott
вручную. Библиотеки и модели речи повторно не скачиваются.
