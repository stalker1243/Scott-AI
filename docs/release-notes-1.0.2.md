# Scott AI 1.0.2

Небольшой выпуск по следам первых установок.

## Что изменилось

**Экран подготовки больше не просвечивает.** Во время первой загрузки
библиотек сквозь него была видна главная страница — кнопки, показания
процессора и статус «online», хотя работать в этот момент ещё нечему. Теперь
экран закрывает окно целиком.

**Заголовок окна** стал «Scott AI»: прежнее «ScottAI (Avalonia)» — след
разработки, людям он ни о чём не говорил.

## Обновление

Скачайте установщик и запустите поверх. Библиотеки и модели речи повторно не
скачиваются.
