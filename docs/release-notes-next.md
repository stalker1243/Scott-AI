# Изменения ScottAI 2.1.0

Эти изменения включены в [выпуск 2.1.0 от 19 октября 2026](release-notes-2.1.0.md).

## Интерфейс

- Новый «Обзор» с визуальным индикатором ScottAI, анимацией состояний
  и запуском голосового режима.
- Компактные страницы, единые отступы и оформление меню.
- Русский, английский, немецкий и испанский языки с переключением без перезапуска.
- Персонализация со стилями, акцентными цветами и отдельным Скоттом Младшим.
  Движение плеча и локтя при приветствии переработано.
- Мини-чат питомца для разговора вне главного окна.

## Возможности и надёжность

- Действия из обычной просьбы в чате, история диалогов, вложения и код
  с подсветкой и копированием.
- Команды приложений и окон, протоколы и управление памятью.
- Отдельное окно обновления с прогрессом и проверкой загруженного файла.
- Проверки Origin/Host для HTTP и WebSocket, ограничение загрузок,
  защита опасных вызовов старого API.
- Ошибки с подсказкой, кодом и идентификатором для архива логов.
- При неполной установке звука голосовые маршруты остаются доступны
  и объясняют, что нужно проверить настройки звука.
- Обновлённые библиотеки HTTP и разбора документов.
- Обновлённый профиль PyTorch и совместимый SDK Scott Voice; Gradio не нужен
  голосовому worker. Эталон и веса голоса сохраняются.
- Мягкая цифровая окраска стандартного профиля Scott без задержки и изменения
  высоты или темпа; обновление голосовых файлов сохраняет пользовательские правки.
- Мужской каталог голосов, включая резерв; прежний выбор женского голоса
  заменяется доступным мужским при чтении настроек.
- Возобновляемая загрузка CPU/CUDA-wheel с проверкой SHA256. При сбое
  установки SDK уже готовый PyTorch не скачивается повторно.

Проверки и известные ограничения перечислены в [примечаниях 2.1.0](release-notes-2.1.0.md#проверки-и-ограничения).
