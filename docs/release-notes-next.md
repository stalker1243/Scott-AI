# Изменения ScottAI

Описание версии 2.2.0: [интерфейс и надёжность](release-notes-2.2.0.md).
Общие инструкции собраны в [руководстве пользователя](guide.md).

В 2.2.0 входят адаптивное окно и плавные переходы, обновлённый чат,
Скотт Младший с мини-чатом и микрофоном, упрощённая память,
восстановление backend и отдельная установка Scott Voice.

Сайт, аккаунты, подписки и облачный голос относятся к будущим обновлениям.
Для языковой модели используется собственный API Token. Linux остаётся beta;
синтез Scott Voice подтверждён на Windows x64 с NVIDIA CUDA.
