# Чат и установка Qt

## Как пользоваться

На вкладке «Диалог» кнопка «История» открывает боковую панель сохранённых
чатов с поиском по названию. Текущий диалог выделен, у каждого видны дата
и число сообщений. «+ Новый» создаёт новый диалог. Меню «…» позволяет
переименовать, очистить или удалить текущий чат; внизу истории можно удалить
все диалоги после подтверждения. Открытие панели не сбрасывает черновик.

«Файл» и «Фото» открывают выбор вложений. Файлы можно перетащить в окно.
Перед отправкой видны имена и миниатюры; каждый файл можно убрать отдельно.
Enter отправляет сообщение, Shift + Enter добавляет строку. При ошибке
черновик и вложения сохраняются.

Для команды компьютеру включите «Действие». Для генерации изображения
выберите подходящую модель на вкладке «Модели» и включите «Картинка».
Результат появляется в переписке с кнопкой «Сохранить».

## Возможности моделей

Кнопка «Модель ↗» открывает выбор модели, где показаны четыре возможности:

| Значок | Что поддерживает приложение |
|---|---|
| Файлы | Извлечение текста документов и передача разговорной модели |
| Фото | Передача изображения модели, которая умеет его анализировать |
| Видео | Передача ролика совместимой модели OpenRouter |
| Генерация | Создание изображения по тексту через OpenAI или OpenRouter |

Для OpenRouter возможности приходят из каталога входных и выходных
модальностей. Для остальных провайдеров используются сведения о поддерживаемых
семействах моделей. У неизвестного ID поддержка фото, видео и генерации
не подтверждается. Значок не гарантирует доступ с конкретным токеном:
провайдер может требовать оплату, доступ к модели или иметь собственные лимиты.

Нажатие на значок показывает пояснение. Кнопки «Фото», «Файл» и «Картинка»
остаются видимыми. Предупреждение появляется после нажатия на функцию,
до открытия окна выбора файла. При входе в чат оно не показывается.
Если модель не поддерживает функцию, предупреждение отображается
с её названием и кнопкой перехода в «Модели». Для неизвестного ID приложение
пишет «поддержка не подтверждена». Вложения и черновик сохраняются;
неподдерживаемый запрос не отправляется. Проверка повторяется перед отправкой,
в том числе после смены модели.

Генерация использует [OpenAI Images API](https://developers.openai.com/api/docs/guides/image-generation)
или [OpenRouter Images API](https://openrouter.ai/docs/guides/overview/multimodal/image-generation).
Видео передаётся в формате [OpenRouter video input](https://openrouter.ai/docs/guides/overview/multimodal/videos).

## Форматы и ограничения

- До четырёх файлов за сообщение, общий размер до 20 МиБ.
- Фото: PNG, JPEG, WebP, GIF, BMP; до 32 миллионов пикселей. Большие снимки
  уменьшаются до 1568 пикселей по длинной стороне. У GIF используется первый кадр.
- Документы: PDF, DOCX, TXT, Markdown, CSV, JSON, XML, YAML, журналы и
  распространённые исходники. Для PDF разбираются первые 40 страниц;
  из одного документа берётся до 24 000 символов. О сокращении текста
  приложение сообщает. Сканированный PDF автоматически в текст не распознаётся.
- Видео: MP4, MPEG, MOV, WebM, только через модель OpenRouter со значком «Видео».
  Приложение не извлекает кадры или звук самостоятельно.
- Сообщение: до 12 000 символов; вопрос вместе с текстом документов — до 30 000.
- Провайдер может задавать более строгий предел. Например,
  [Groq Qwen3.8](https://console.groq.com/docs/vision) принимает до трёх фото.
- Генерация пока работает по тексту, создаёт одно изображение и сохраняет PNG.
  Редактирование по приложенной фотографии ещё не добавлено.

В запрос входят до десяти последних завершённых пар сообщений текущего чата,
с ограничением объёма текста, и найденные записи долговременной памяти.
Последние фото повторно передаются на уточняющий вопрос, если выбранная модель
поддерживает их анализ. При новых фото используются новые вложения.
Видео отправляется в исходном запросе; для повторного анализа ролик нужно
прикрепить снова. В последующих сообщениях остаётся текст предыдущего ответа.

## Хранение и очистка

Чаты и файлы находятся локально в `backend/data/chats`. Вопросы, содержимое
документов и необходимые изображения передаются выбранному провайдеру.
Переписка до появления именованных чатов однократно импортируется в диалог
«Предыдущая переписка». После удаления она не появляется заново.

Удаление и очистка убирают вложения и связанные записи памяти разговоров,
включая поисковый индекс. Очистка сохраняет название чата; удаление убирает
сам диалог. Отдельно сохранённые факты о пользователе остаются в «Памяти».
Общая очистка истории во вкладке «Память» очищает также именованные чаты.

## Установщик

```powershell
python installer/build.py --installer
```

Результат: `installer/release/ScottAI-<версия>-Qt-setup.exe`. Включены
Python, backend, Qt и библиотеки компилятора. Для сборки нужны Qt/MinGW,
CMake, Ninja и Inno Setup; параметры путей перечислены в `--help`.
Для Avalonia используйте `--launcher avalonia`.

Установщик использует тёмный мастер с логотипом. Первый запуск показывает
подготовку библиотек и моделей речи: нужны интернет и около 5 ГБ места.
Доступны прогресс, отмена и повторная попытка после ошибки. Личные настройки,
API Token, история и файлы разработчика в дистрибутив не включаются.
Библиотеки развёрнуты через [Qt windeployqt](https://doc.qt.io/qt-6/windows-deployment.html),
оформление мастера использует [Inno Setup modern dark](https://jrsoftware.org/ishelp/topic_setup_wizardstyle.htm).

## Проверка изменения

Проверены сохранение и очистка чатов, фактические байты вложений, ограничения
моделей, контекст фотографии, отзывчивость статуса во время ответа, ошибки
провайдеров и сохранение черновика. Qt проверяется на локальном тестовом сервере
и вымышленных данных во всех трёх стилях, включая окно 800×560.

Установщик собран, его приветственный экран проверен. Комплект Qt запускается
без Qt в PATH. Первый запуск проверен тестовым процессом; полная установка
моделей на чистом компьютере ещё предстоит. Платные запросы на генерацию
в этих проверках не отправлялись.
