## Найденная и исправленная ошибка

На коротком разговоре продолжение проекта работало, поскольку нужная запись
случайно помещалась среди четырёх выбранных старых разговоров. После 18
посторонних тем backend передал арифметические вопросы и пропустил решение
по проекту. Модель прямо ответила, что не знает состояние проекта.

Причина: слова «продолжим», «остановились» и похожие переключали подбор
на последние 40 ответов без учёта названной темы. Теперь такие вопросы
используют индекс всего архива и недавние записи как запасной источник.
Совпадения по теме получают приоритет; общие слова продолжения исключаются
из поисковых терминов. Лимит четырёх пар и 2000 символов сохранён.
Для этого не добавлены модельные запросы или зависимости.

Добавлены регрессионные проверки: нужный проект за пределами последних
40 ответов, выбор между разными проектами и продолжение без названия темы.
До исправления две проверки падали; после исправления прошли все три.

Полный автономный набор backend: **1399 passed, 7 deselected, 3 warnings**,
212,04 с. Проверки живого сервера и медленные проверки исключены:

```powershell
py -3.13 -m pytest backend/tests -q -m 'not integration and not slow'
```

Лог: `reports/backend-memory-live-2026-10-05/pytest-complete.log`.
Отдельно прошли 54 проверки памяти и 9 проверок инструмента оценки.

Автоматическая оценка первого прогона ошибочно отклонила «Mikhail» как новое
имя; ручная проверка подтвердила правильный ответ. Оценка теперь принимает
эту транслитерацию и по-прежнему отвергает прежнее имя.

## Изоляция и воспроизводимость

Новый `backend/check_memory.py` запускает настоящую модель только с `--live`.
Каждый сценарий начинается в отдельном процессе с копией вымышленной памяти.
Настоящие пользовательские факты, диалоги, проекты и характер не подмешиваются.
Исполнитель команд и голос не запускаются. Тестовые файлы удаляются после
прогона, ключи не сохраняются в отчётах. В тестах самого инструмента
проверено отсутствие сети без `--live` и сохранность исходных файлов.

Изначальные ответы модели и дополнительные посторонние диалоги получены
настоящими запросами. Повтор после исправления использовал ту же вымышленную
историю из отчёта, чтобы сравнить подбор, и получил новые настоящие ответы
на все проверочные вопросы.

Окончательный отчёт: `reports/backend-memory-live-2026-10-05/run-nxk4x0p4/report.json`.
Исходный расширенный прогон с провалом продолжения:
`reports/backend-memory-live-2026-10-05/run-yh7yxltq/report.json`.
Короткий исходный прогон: `reports/backend-memory-live-2026-10-05/run-m5a0566u/report.json`.

После применения исправления приложение перезапущено: backend отвечает
`online`, окно Qt отвечает, голос не активен. В пользовательском архиве
остались 579 разговоров, тестовых фактов нет, предупреждение памяти пустое.
Состояние без текстов и ключей: `reports/backend-memory-live-2026-10-05/live-state.json`.

Поиск остаётся лексическим. Понимание перефразирования без общих слов
нужно проверять отдельно; поиск по смыслу ещё не реализован.
