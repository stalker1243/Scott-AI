# Backend: поддержка AMD, 5 октября 2026

Добавлена первичная поддержка AMD ROCm/HIP для Whisper и Silero.
Инструкция: [amd-support.md](amd-support.md).

## Что изменилось

- PyTorch с HIP определяется как AMD. Он использует внутреннее имя устройства
  `cuda`, но в интерфейсе и диагностике показывается отдельно от NVIDIA.
- Настройки движков принимают `rocm`. Qt получает список доступных вариантов
  и показывает кнопки NVIDIA/AMD/Процессор. Прежние переменные `cuda` в
  HIP-окружении продолжают работать. Сохранение устройств атомарное;
  запросы настроек и сброс моделей выполняются в рабочих потоках HTTP-сервера.
- Whisper на AMD GPU выбирает PyTorch вместо готовой CUDA-сборки CTranslate2.
  После HIP/MIOpen/rocBLAS-сбоя или нехватки памяти пробует CPU один раз
  и сохраняет CPU-модель для следующих запросов.
- Silero при ошибке GPU пробует локальный синтез на CPU. Смена устройства
  не выгружает модель посреди записи WAV.
- Диагностика отличает HIP-сборку, доступность ROCm и установленные адаптеры AMD.
  Подготовка зависимостей выбирает официальный AMD-профиль и сохраняет уже
  установленный HIP. Ошибка установки ROCm допускает подготовку CPU-версии.
- `backend/setup_amd.py` показывает план по умолчанию; `--install` работает
  в отдельном виртуальном окружении и проверяет небольшое вычисление на GPU.

Qt и backend перезапущены. На этой машине сохраняется NVIDIA CUDA:
PyTorch 2.9.1+cu126, RTX 3060, 12 ГБ; `rocm_available=false`.
Команды компьютеру не выполнялись, воспроизведение не включалось.
Библиотеки ROCm и драйвер AMD на эту машину не устанавливались.

Логи, синтетические WAV/MP3 и JSON результатов находятся в игнорируемой
папке `reports/backend-amd-2026-10-05/`.

## Что ещё нужно проверить

Физической AMD-карты здесь нет. Реальные загрузка моделей, скорость и
совместимость драйвера с конкретной Radeon ещё не проверены. Подменённые
тесты подтверждают выбор веток и обработку ошибок, но не заменяют эту проверку.
DirectML и показатели нагрузки AMD GPU пока не реализованы.
Поле `device` в настройках отражает устройство для загрузки модели;
последующий переход на CPU виден в логе.
