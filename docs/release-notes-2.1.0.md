# Scott AI 2.1.0

19 октября 2026 · build 14 · Windows x64 и экспериментальный Linux x86-64.

## Интерфейс и Скотт Младший

- Новый «Обзор» с анимированным индикатором состояния и запуском микрофона.
- Компактная навигация, единые меню и страницы, стили и акцентные цвета
  в «Персонализации» слева снизу.
- Русский, английский, немецкий и испанский интерфейс; язык меняется без перезапуска.
- Скотт Младший на рабочем столе: размер, перемещение, эмоции и реакции на события.
  Правый клик открывает мини-чат или скрывает питомца. Он выключается отдельно
  и может оставаться после закрытия лаунчера.
- История диалогов, вложения, отдельные блоки кода с подсветкой и копированием.
  Доступные действия вызываются обычной просьбой в чате или голосом.

## Команды и backend

- Каталог установленных приложений и команды окон: открыть, найти, переключить,
  свернуть, развернуть и закрыть. «Закрой все окна» использует обычное закрытие,
  без принудительного завершения; запрос сохранения документа сохраняется.
- Управление доступными кнопками по названию в Windows, необязательный браузер
  для поиска и воспроизведения видео, новые локальные команды и протоколы.
- Ограничены параллельная работа, загрузки и ожидание ответа. Поздний ответ после
  отмены не записывается в диалог и не отправляется повторно автоматически.
- Проверки Host/Origin и WebSocket, защита опасных вызовов прежнего API,
  обновлённые библиотеки HTTP и документов.
- Понятные коды ошибок и подсказки; диагностика собирается в архив во вкладке «Логи».

## Установка, обновление и голос

- Отдельное окно обновления с прогрессом, проверкой SHA256 и повторным запуском.
- Возобновляемая загрузка CPU/CUDA-компонентов с проверкой целостности.
  При повторе установки SDK уже готовый PyTorch не скачивается заново.
- Совместимый SDK Scott Voice с обновлёнными зависимостями. Принятый профиль B
  добавляет мягкую цифровую окраску без задержки и изменения темпа или высоты.
- В выборе, командах и API остались мужские голоса. Старый женский выбор
  заменяется доступным мужским при чтении; пользовательские настройки не стираются.
- Linux tar.gz и AppImage с постоянным окружением Python вне образа,
  сохранением данных при обновлении и запуском AppImage без FUSE через распаковку.

## Обновление с 2.0.1

Обновляйте в прежнюю папку. Сначала сохраните копию `.env` и `backend/data`;
на Linux — также каталогов данных и настроек из [инструкции](linux.md).
Питомца из старой кешированной копии выключите и включите в «Персонализации».
Если Scott Voice уже установлен, выполните его штатное обновление в настройках:
основной установщик сохраняет рабочее окружение и веса голоса.

Размеры файлов выпуска не включают модели и библиотеки, загружаемые при первой
подготовке. CPU требует нескольких гигабайт; GPU и Scott Voice — больше.
[Установка и размер](installation.md), [голос](voice.md), [Linux](linux.md).

## Проверки и ограничения

Полные наборы backend: Windows 2527 тестов, Linux 2559; проверки Qt,
установки и повторного обновления, AppImage через распаковку и FUSE пройдены.
Пользователь подтвердил запуск, микрофон, голосовой ответ и остановку через трей
в текущем приложении; точный build этой ручной проверки не зафиксирован.

Linux остаётся экспериментальным: свежие пакеты проверены в Debian 12 в изоляции,
X11 и Wayland — через тестовые окружения. Физические Fedora/Arch, GNOME/KDE,
AMD, микрофон и несколько мониторов с разным DPI требуют дальнейшей проверки.
На Wayland управление чужими окнами ограничено; Glass-размытие рабочего стола
доступно в Windows. Scott Voice проверен на Windows/NVIDIA; генерация новых фраз
может быть медленной, отдельные огрехи произношения остаются. Полной автоматизации
любого приложения через зрение пока нет.
