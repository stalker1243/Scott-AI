# Протоколы

Функция временно отключена в текущих исходниках: она требует отдельной доработки.
В лаунчере нет вкладки протоколов. Backend не загружает сохранённое хранилище,
поэтому голосовой вызов, запуск через API и выполнение по расписанию недоступны.
Сохранённые файлы не удаляются. Отдельные команды приложений, окон, браузера
и напоминания продолжают работать через чат и микрофон.

Эта правка пока не входит в опубликованную 2.1.1.
