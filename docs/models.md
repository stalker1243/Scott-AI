# Модели в ScottAI

Каталог обновлён 8 октября 2026 года. В разделе **Модели** выберите
провайдера, модель и добавьте свой API Token. Сохранённый выбор пользователя
при обновлении не меняется. Доступ зависит от аккаунта и тарифа провайдера.

| Провайдер | Новые варианты в списке |
|---|---|
| OpenAI | GPT-6.1 Sol, GPT-6 Astra, GPT-6 Luna, GPT-Image 2 |
| Anthropic | Claude Sonnet 5.5, Opus 5.5, Haiku 5.5, Fable 5.1 |
| DeepSeek | V4.1 Flash (`deepseek-flash`), V4 Pro (`deepseek-v4-pro`) |

API ID проверены по официальным страницам:
[OpenAI](https://developers.openai.com/api/docs/models/all),
[Claude](https://platform.claude.com/docs/en/models/overview),
[DeepSeek](https://api-docs.deepseek.com/updates/).
Groq и OpenRouter продолжают получать список доступных моделей от провайдера;
для Claude список аккаунта также имеет приоритет над запасным каталогом.
Неизвестный ID можно ввести вручную.

Значки показывают возможности, доступные через Scott. Фото поддерживают
новые GPT и Claude, а также DeepSeek Flash; у DeepSeek V4 Pro поддержка
фото в Scott не подтверждена. Генерация изображений выполняется отдельными
моделями GPT-Image. Наличие инструментов генерации или видео в API провайдера
не означает, что Scott подключает их для каждой чат-модели.

Новые модели с рассуждениями используют лимит, который включает рассуждения
и видимый ответ: Scott оставляет минимум 8192 токена. Это верхний предел,
а не обязательный расход. У новых Claude не передаётся неподдерживаемая
температура; для GPT-6 Luna выбрано рассуждение `none`, для Astra и Sol — `low`,
чтобы ограничить задержку обычного диалога.
GPT используют `max_completion_tokens`. Совместимость формата
проверена без платных запросов; ответы и задержка на реальных аккаунтах
в этой проверке не измерялись.
