# Backend: загрузка аудио и голосовые команды — 5 октября 2026

Продолжение [первой проверки](backend-audit-2026-10-05.md).

## Исправления

- Каждый запрос `/speech_to_text` получает отдельную временную папку.
  Файлы с одинаковыми именами больше не перезаписывают друг друга. Имя от
  клиента остаётся в ответе, но не используется как путь для записи.
- Декодирование, усиление и распознавание аудио выполняются в рабочем потоке.
  Отмена HTTP-запроса не удаляет файл, который ещё читает распознаватель;
  поток сам очищает свою папку после работы. Тихая запись преобразуется
  в отдельный WAV, включая исходные MP3.
- При ошибке CUDA/cuDNN/cuBLAS или нехватке памяти GPU Whisper один раз
  повторяет распознавание на CPU и продолжает использовать эту модель.
  Обычная ошибка аудио не переключает устройство; ошибка CPU не вызывает
  бесконечные повторы. Проверены оба движка, включая отложенную ошибку
  при чтении сегментов faster-whisper.
- Обычный Whisper теперь использует подсказку словаря, две температуры
  декодирования и существующий фильтр выдуманных фраз. Проверка наличия речи
  в длинных массивах аудио применяется к обоим движкам. Подсказка содержит
  имена голосов и названия, без готовых приказов. Параметры `initial_prompt`
  и `temperature` предусмотрены в
  [исходном коде Whisper](https://github.com/openai/whisper/blob/main/whisper/transcribe.py).
- Запятые между словами от распознавания больше не мешают понять громкость
  голоса. Некорректное число получает объяснение. Десятичная запись вроде
  `50,5` не превращается в целое число и не уходит в управление системным звуком.
- Вопрос «чем отличается HTTP от HTTPS» получает ответ, включая обращение
  «Скотт». В команде «заверши процесс chrome» исполнителю передаётся `chrome`.
  Исправлены найденные варианты «браузера», «прибав яркость», «заеди на GitHub»
  и ошибки имён в явных командах выбора голоса.

## Управление голосом

| Фраза | Результат |
|---|---|
| Покажи голоса / какие голоса есть? | Все доступные имена каталога |
| Выбери голос Уильяма | Выбор и сохранение голоса |
| Выбери голос Флориана | Выбор и сохранение голоса |
| Громкость голоса пятьдесят пять процентов | Громкость речи 55% |
| Говори тише / говори громче | Изменение на 10 процентов |

Выбирать можно все 11 голосов по имени из каталога или по идентификатору.
Команды проходят общий путь чата, голосового обработчика и протоколов.
Параллельные относительные изменения громкости больше не теряют прибавления.
В микрофоне по-прежнему требуется обращение «Скотт».

## Оставшиеся ошибки

В синтетическом наборе слово «борща» иногда распознаётся неверно. У Айдара
изменяется фраза памяти «работаю над ScottAI», а имя проекта звучит как
«Скотт AI». Эти случаи сохранены как промахи: изменённый запрос или факт
может повлиять на результат. Проверка живой речи, комнаты и микрофона ещё нужна.

Команды в тестах проверялись на подменённых исполнителях. В HTTP-проверке
созданы только искусственные записи; микрофон и динамики не включались,
команды из распознанного текста не выполнялись. Личная память и API Token
не менялись. Исходники Qt в этом проходе не менялись.
