# Scott AI 2.0 — новый интерфейс, диалоги и память

Крупное обновление Scott AI для Windows. Основным интерфейсом стал лаунчер
на C++ и Qt Quick. Следующие выпуски 2.0.x будут сосредоточены на исправлениях
ошибок и улучшении устойчивости.

## Новый интерфейс

- Три оформления: Classic, Glass с размытием рабочего стола и Terminal Pro.
- Компактная навигация, светлая и тёмная темы, цвет акцента и новые иконки.
- Анимации открытия, закрытия, сворачивания и изменения состояния окна.
- Работа в трее: открытие разделов, тихий режим, пауза голосового ассистента,
  закрепление окна и уведомления.

## Чат и модели

- Отдельные диалоги с историей, переименованием, очисткой и удалением.
- Вложения: фотографии и документы, перетаскивание файлов, сохранение результатов.
- Возможности моделей показываются в интерфейсе. Если модель не поддерживает
  выбранную функцию, предупреждение появляется при её выборе.
- Свои API Token и выбор провайдера/модели. Поддержка изображений, видео
  и генерации изображений зависит от выбранной модели и её API.

## Память и действия

- Факты и завершённые разговоры сохраняются между запусками.
- Локальный поиск памяти по словам и смыслу, управление записями в интерфейсе.
- Редактор протоколов, последовательности действий, результаты выполнения
  и управление заданиями.
- Улучшена обработка ошибок поиска и моделей, чтобы не терять работу backend.

## Голос

- Общий путь Whisper для микрофона и аудиофайлов, обработка тихой речи и тишины.
- Выбор голоса, характера, устройств и громкости; прослушивание в настройках.
- Необязательный Scott Voice: мужской голос с цифровыми вариантами,
  отдельная установка, резервный голос, кеш и отмена синтеза.
- Ручная подготовка Scott Voice перед разговором и освобождение модели.
  Без запросов модель освобождает память через две минуты.
- Экспериментальные раннее начало речи, ускоренный синтез и запас звука
  доступны отдельными настройками и по умолчанию выключены.

Scott Voice пока проверен на NVIDIA/CUDA. Генерация новых фраз может занимать
заметное время; в раннем режиме возможны паузы. Поддержка AMD для Whisper
и Silero экспериментальная и требует совместимой карты, драйвера и PyTorch.
Scott Voice на AMD/CPU ещё не проверен.

## Установка и сохранение данных

Windows-установщик включает Qt и Python; зависимости и модели речи
готовятся при первом запуске. Scott Voice устанавливается отдельно.
Обновление выполняется в прежнюю папку установки.

История, вложения и настройки моделей используют постоянные пути внутри
`backend/data`, которые не зависят от рабочей папки запуска. При удалении
приложения эти данные сохраняются по умолчанию. Интерактивное удаление
предлагает удалить их отдельно; тихое удаление сохраняет их.
Введённые API Token также входят в сохранённые настройки моделей.

Перед обновлением рекомендуется сохранить копию папки `backend/data`
и собственного `.env`. Версия 2.0 не переносит и не объединяет автоматически
старые базы из другой папки установки.

Этот выпуск предназначен для Windows x64. Avalonia и мобильное приложение
сохраняются в исходниках; прежние Linux/macOS-дистрибутивы относятся к 1.2.
