# Scott AI 2.0.1

Исправляющий выпуск для Windows x64 и экспериментальный пакет для Linux x86-64.

## Первая подготовка

- Отдельное окно загрузки: основной интерфейс появляется после готовности.
- Загрузка Whisper продолжается после остановки и обрыва соединения.
  Файл используется после полной проверки SHA256; проверка не отключается.
- Повтор после ошибки моделей использует готовые библиотеки.
- Прогресс показывает скачанный объём. Есть остановка, продолжение и повтор.
- Компактная CPU-установка готовит чат и голос; GPU определяется автоматически
  при обычной установке. Выбранная модель Whisper сохраняется.

## Профиль и модели

- Увеличенный редактор аватара: круг кадра, перетаскивание, масштаб колесом,
  стрелки, сброс и отмена. Широкие и вертикальные фото можно сдвигать при 100%.
- Новые модели GPT-6, Claude 5.5/Fable 5.1 и DeepSeek V4.1 Flash/V4 Pro.
  Формат запросов и значки возможностей обновлены. Подробнее — [модели](models.md).

## Размер и Linux

- Убраны неиспользуемые Qt Control-стили; лицензии сохранены в ZIP.
  Базовый Windows-пакет уменьшен примерно с 176 до 123 МиБ.
- Подготовка не сохраняет вторую копию скачанных пакетов в общем кеше pip.
  Резерв компактного Windows-установщика — 2,5 ГиБ сверх базового пакета.
- Linux-архив включает Qt и собственный Python 3.13.16. Установка не требует
  системный Python и выполняется без sudo после установки системных библиотек.
  [Инструкции для Fedora, Arch, Ubuntu и Debian](linux.md).

История, API Token, вложения и настройки сохраняются при обновлении
в прежнюю папку. Scott Voice устанавливается отдельно.

Linux пока использует X11/XWayland. Проверки в контейнерах и Xvfb не заменяют
проверку микрофона, аудиоустройств, трея и GPU на настоящем рабочем столе.
Scott Voice на Linux ещё не проверен. Подробности — [установка](installation.md).
