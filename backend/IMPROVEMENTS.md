# Улучшения системы ответов на вопросы

## Что было добавлено

### 1. Анализатор вопросов (`question_analyzer.py`)

Система автоматически определяет:
- **Категорию вопроса**: простой, математика, наука, общий
- **Сложность**: лёгкий, средний, сложный
- **Требования**: нужны ли расчёты, рассуждения

### 2. Улучшенные промпты

Система использует специальные промпты для разных типов вопросов:

- **Математика**: "Ты опытный математик. Отвечай точно, показывай шаги решения."
- **Наука**: "Ты учёный-энциклопедист. Отвечай научно обоснованно, но доступным языком."
- **Простые**: "Отвечай дружелюбно и кратко."
- **Общие**: "Отвечай развёрнуто и информативно."

### 3. Автоматические вычисления

Для простых математических выражений (2+2, 10*5) система может вычислить ответ напрямую, без обращения к LLM.

### 4. Адаптивные ответы

В зависимости от сложности вопроса система:
- **Лёгкие**: даёт краткие ответы
- **Средние**: даёт ответы с примерами
- **Сложные**: даёт подробные развёрнутые ответы с объяснениями

## Примеры вопросов

### Простые (easy):
- "Привет, как дела?"
- "Что ты умеешь?"
- "Который час?"

### Средние - математика (medium):
- "Сколько будет 15 + 27?"
- "Вычисли 100 * 5"
- "Сколько процентов от 200 составляет 50?"

### Средние - наука (medium):
- "Что такое молекула?"
- "Как работает фотосинтез?"

### Сложные - математика (hard):
- "Реши уравнение: 2x + 5 = 15"
- "Что такое производная функции?"
- "Объясни теорему Пифагора"

### Сложные - наука (hard):
- "Почему небо голубое?"
- "Как работает гравитация?"
- "Расскажи о квантовой физике"

## Тестирование

Запусти тест для проверки всех типов вопросов:

```bash
cd backend
python test_questions.py
```

Этот тест проверит:
1. Работу анализатора вопросов
2. Ответы на простые вопросы
3. Ответы на средние математические вопросы
4. Ответы на сложные научные вопросы
5. Ответы на сложные математические вопросы

## Использование в коде

```python
from llm_core import LlmEngine, LlmConfig

# Настройка Ollama
config = LlmConfig(provider="ollama", model="qwen2.5:7b")
llm = LlmEngine(config=config)

# Система автоматически определит тип вопроса и даст подходящий ответ
answer = llm.answer("Сколько будет 25 * 4?")
print(answer)  # Результат: 100

answer = llm.answer("Почему небо голубое?")
print(answer)  # Подробный научный ответ
```
