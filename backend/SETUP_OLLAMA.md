# Инструкция по настройке Ollama

Ollama - это бесплатный инструмент для запуска LLM моделей локально на твоём компьютере. **Не требует API ключей!**

## Преимущества Ollama

- ✅ **Бесплатно** - полностью бесплатно
- ✅ **Локально** - работает на твоём компьютере
- ✅ **Приватно** - данные не отправляются в облако
- ✅ **Офлайн** - работает без интернета (после скачивания модели)
- ✅ **Без API ключей** - не нужно регистрироваться

## Шаг 1: Установка Ollama

### Windows:

1. Перейди на https://ollama.ai/download
2. Скачай установщик для Windows
3. Запусти установку и следуй инструкциям
4. Ollama автоматически запустится после установки

### Альтернатива (через командную строку):

Если у тебя есть WSL (Windows Subsystem for Linux), можешь использовать Linux версию.

## Шаг 2: Скачивание модели

После установки Ollama, открой терминал/командную строку и выполни:

```bash
ollama run llama3.2
```

Эта команда:
- Скачает модель llama3.2 (если её ещё нет)
- Запустит интерактивный чат

**Популярные модели:**
- `llama3.2` - хороший баланс качества и скорости (рекомендуется)
- `llama3.1` - более мощная, но медленнее
- `mistral` - быстрая и эффективная
- `qwen2.5` - поддерживает много языков, включая русский
- `deepseek-r1` - очень умная модель

Для русских ответов рекомендую:
```bash
ollama run qwen2.5:7b  # Хорошо понимает русский
```

Или:
```bash
ollama run llama3.2  # Универсальная модель
```

**Важно:** Первое скачивание модели может занять несколько минут (модели большие, 2-7 ГБ).

## Шаг 3: Проверка работы

В терминале выполни:
```bash
ollama list
```

Должна отобразиться список установленных моделей.

Проверь, что Ollama работает:
```bash
curl http://localhost:11434/api/tags
```

Или открой в браузере: http://localhost:11434/api/tags

## Шаг 4: Настройка в проекте

После установки Ollama и скачивания модели, используй Ollama в коде:

```python
from llm_core import LlmEngine, LlmConfig

config = LlmConfig(
    provider="ollama",
    model="llama3.2"  # или другая модель, которую ты скачал
)

llm = LlmEngine(config=config)
answer = llm.answer("Привет, как дела?")
print(answer)
```

## Шаг 5: Тест

Запусти тестовый скрипт:
```bash
cd backend

```

Или протестируй через чат-бота:
```python
from llm_core import LlmEngine, LlmConfig
from chatbot import ChatBot, ChatBotConfig

# Настройка LLM для Ollama
llm_config = LlmConfig(provider="ollama", model="llama3.2")
llm = LlmEngine(config=llm_config)

# Использование в чат-боте
from chatbot import ChatBotConfig
chatbot_config = ChatBotConfig(llm_engine=llm)
chatbot = ChatBot(config=chatbot_config)

result = chatbot.process_text_question("Привет! Расскажи о себе.")
print(result["answer_text"])
```

## Решение проблем

### Ollama не запускается

- Убедись, что Ollama установлен правильно
- Перезапусти компьютер
- Проверь, что порт 11434 не занят другим приложением

### Модель не скачивается

- Проверь подключение к интернету (требуется только для первого скачивания)
- Убедись, что есть достаточно места на диске (модели занимают 2-7 ГБ)

### Медленная работа

- Используй более маленькую модель (например, llama3.2 вместо llama3.1)
- Убедись, что у тебя достаточно RAM (рекомендуется 8+ ГБ)
- Закрой другие тяжёлые приложения

### Ошибка подключения в Python

- Убедись, что Ollama запущен
- Проверь: `curl http://localhost:11434/api/tags`
- Если не работает, перезапусти Ollama

## Полезные команды Ollama

```bash
# Список установленных моделей
ollama list

# Удалить модель
ollama rm llama3.2

# Показать информацию о модели
ollama show llama3.2

# Запустить интерактивный чат
ollama run llama3.2
```

## Рекомендации

- **Для начала:** `llama3.2` или `qwen2.5:7b` (хорошо понимает русский)
- **Для скорости:** `mistral` (самая быстрая)
- **Для качества:** `llama3.1:70b` (но требует много RAM)
