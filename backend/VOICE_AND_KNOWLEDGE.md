# Голосовые ответы и система знаний

## Что добавлено

### 1. 🎙️ Голосовые ответы (TTS)

Добавлена поддержка **edge-tts** (Microsoft Edge TTS) для качественного синтеза речи:

- ✅ **Работает с Python 3.13**
- ✅ **Бесплатно**
- ✅ **Качественный голос** на русском языке
- ✅ **Быстрое озвучивание**

**Доступные голоса для русского:**
- `ru-RU-SvetlanaNeural` - женский (по умолчанию)
- `ru-RU-DmitryNeural` - мужской
- И другие (можно посмотреть список)

### 2. 📚 База знаний

Создана система знаний с предзагруженной информацией:

- ✅ **История** - Древняя Русь, Пётр I, Великая Отечественная война
- ✅ **Наука** - физика, химия, биология (гравитация, вода, фотосинтез)
- ✅ **География** - Россия, Москва
- ✅ **Культура** - Пушкин, Толстой
- ✅ **Общее** - Земля, Солнечная система

Система автоматически находит релевантные знания для вопросов и использует их в ответах.

## Использование

### Тест голосового чат-бота с знаниями:

```bash
cd backend
python test_voice_chatbot.py
```

Это создаст голосовые ответы на вопросы из разных областей знаний.

### В коде:

```python
from llm_core import LlmEngine, LlmConfig
from tts_core import TtsEngine, TtsConfig
from knowledge_base import KnowledgeBase
from chatbot import ChatBot, ChatBotConfig

# Настройка LLM с знаниями
knowledge_base = KnowledgeBase()
llm_config = LlmConfig(provider="ollama", model="qwen2.5:7b")
llm = LlmEngine(config=llm_config, knowledge_base=knowledge_base)

# Настройка голоса
tts_config = TtsConfig(provider="edge-tts", voice="ru-RU-SvetlanaNeural")
tts = TtsEngine(config=tts_config)

# Создание чат-бота
chatbot_config = ChatBotConfig(llm_engine=llm, tts_engine=tts)
chatbot = ChatBot(config=chatbot_config)

# Использование
result = chatbot.process_text_question("Расскажи о Пушкине")
print(result["answer_text"])  # Текст ответа
print(result["answer_audio"])  # Путь к голосовому файлу
```

## Расширение базы знаний

Можно добавить свои знания:

```python
from knowledge_base import KnowledgeBase

kb = KnowledgeBase()

# Добавляем новое знание
kb.add_knowledge(
    category="история",
    topic="Екатерина II",
    content="Екатерина II Великая (1729-1796) - императрица России, эпоха 'просвещённого абсолютизма'."
)
```
