# 🚀 Быстрый запуск Мальтруанта

## Способ 1: Через Python (самый простой)

1. Открой терминал (командную строку или PowerShell)
2. Перейди в папку backend:
   ```bash
   cd backend
   ```
3. Запусти:
   ```bash
   python maltruand.py
   ```

## Способ 2: Через bat-файл (Windows)

1. Открой терминал
2. Перейди в папку backend:
   ```bash
   cd backend
   ```
3. Запусти:
   ```bash
   maltruand.bat
   ```
   
   Или просто дважды кликни на файл `maltruand.bat` в проводнике!

## Способ 3: Из любой папки (после установки)

Если установить через setup.py, можно запускать из любой папки:

```bash
maltruand
```

Но для начала используй Способ 1 или 2 - они проще!

## Что будет происходить:

1. ✅ Мальтруант инициализируется
2. ✅ Появится приветствие: "Здравствуйте! Я Мальтруант..."
3. ✅ Приветствие будет озвучено
4. ✅ Появится строка для ввода: `👤 Вы: `
5. ✅ Введи вопрос и нажми Enter
6. ✅ Получишь ответ с голосом!

## Примеры вопросов для начала:

- "Привет"
- "Расскажи о себе"
- "Кто такой Пушкин?"
- "Что такое фотосинтез?"

## Для выхода:

Введи: `выход` или `exit`

Или нажми: `Ctrl+C`
