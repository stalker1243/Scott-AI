# Распознавание речи.
#
# ВАЖНО про torch: обычный `pip install torch` ставит СБОРКУ ДЛЯ ПРОЦЕССОРА,
# даже когда в машине есть NVIDIA-видеокарта. На CPU модель Whisper «small»
# распознаёт короткую фразу ~6.6с, на RTX 3060 — доли секунды, поэтому сборку
# с CUDA нужно ставить явно, отдельной командой и со своего индекса:
#
#   pip install --index-url https://download.pytorch.org/whl/cu126 torch==2.9.1+cu126
#
# Проверить, что видеокарта реально подхватилась:
#   python -c "import torch; print(torch.cuda.is_available())"
# Устройство можно принудительно задать в .env через WHISPER_DEVICE=cuda|cpu.
#
# Версия torch намеренно без верхней границы и без +cu126 в самом файле: пин с
# суффиксом сборки не поставится с обычного индекса PyPI, а команда выше ставит
# нужную сборку сама.
