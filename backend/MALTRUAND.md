# Мальтруант (Maltruand) 🎙️🤖

**Мальтруант** - это голосовой ассистент с искусственным интеллектом, который:
- ✅ Отвечает на вопросы голосом (в стиле Джарвиса)
- ✅ Использует базу знаний (история, наука, культура)
- ✅ Работает локально с Ollama
- ✅ Интерактивный интерфейс в терминале

## Запуск

### Способ 1: Прямой запуск (без установки)

```bash
cd backend
python maltruand.py
```

### Способ 2: Установка команды (рекомендуется)

Установи команду `maltruand` в систему:

```bash
cd backend
pip install -e .
```

Или через setup.py:

```bash
cd backend
pip install -e . --user
```

После установки можно запускать из любой папки:

```bash
maltruand
```

### Способ 3: Создание bat-файла (Windows)

Создай файл `maltruand.bat` в папке `backend`:

```batch
@echo off
cd /d "%~dp0"
python maltruand.py
```

Затем добавь папку `backend` в PATH или запускай через:

```bash
cd backend
maltruand.bat
```

## Использование

После запуска Мальтруант:

1. **Поприветствует тебя**: "Чем могу помочь?"
2. **Озвучит приветствие** (сохранит в файл)
3. **Будет ждать твоих вопросов**

### Команды:

- Введи вопрос - получи ответ с голосом
- `выход` или `exit` - завершить работу
- `Ctrl+C` - прервать работу

### Примеры вопросов:

- "Расскажи о Пушкине"
- "Кто такой Пётр I?"
- "Что такое фотосинтез?"
- "Почему небо голубое?"
- "Сколько будет 25 * 4?"

## Особенности

- 🎙️ **Голос Джарвиса** - глубокий мужской голос, как в фильме "Железный человек"
- 📚 **База знаний** - знает историю, науку, культуру
- 🤖 **Ollama** - работает локально, без API ключей
- 🔊 **Голосовые ответы** - каждый ответ озвучивается
- 💬 **Интерактивный** - можно задавать вопросы в цикле

## Файлы

Мальтруант создаёт файлы:
- `maltruand_greeting.wav` - приветствие
- `maltruand_answer_1.wav` - первый ответ
- `maltruand_answer_2.wav` - второй ответ
- И так далее...

Все файлы сохраняются в папке `backend`.

## Настройка

Можно изменить настройки в файле `maltruand.py`:

- **Голос**: измени `voice_preset="jarvis_ru"` на другой пресет:
  - `"jarvis_ru"` - голос Джарвиса (русский вариант, глубокий) - **текущий**
  - `"jarvis"` - голос Джарвиса (английский, как в фильме)
  - `"robot_light"` - лёгкий роботический (высокий, быстрый)
  - `"robot_light_female"` - лёгкий роботический (женский)
  - `"russian_male"` - стандартный мужской
  - `"russian_female"` - стандартный женский
- **Модель LLM**: измени `model="qwen2.5:7b"` на другую модель
- **Язык**: измени `language="ru"` на другой язык
