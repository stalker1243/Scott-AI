# Инструкция по настройке OpenAI API

## Шаг 1: Получение API ключа OpenAI

1. Перейди на сайт OpenAI: https://platform.openai.com/
2. Зарегистрируйся или войди в свой аккаунт
3. Перейди в раздел **API Keys**: https://platform.openai.com/api-keys
4. Нажми кнопку **"Create new secret key"**
5. Скопируй ключ (он показывается только один раз! Сохрани его в безопасном месте)

## Шаг 2: Установка API ключа

### Вариант А: Через переменную окружения (рекомендуется)

**В Windows (PowerShell):**
```powershell
# Временно (на текущую сессию)
$env:OPENAI_API_KEY="sk-твой-ключ-здесь"

# Постоянно (для текущего пользователя)
[System.Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-твой-ключ-здесь", "User")
```

**В Windows (cmd):**
```cmd
# Временно
set OPENAI_API_KEY=sk-твой-ключ-здесь

# Постоянно
setx OPENAI_API_KEY "sk-твой-ключ-здесь"
```

**В Linux/Mac:**
```bash
# Добавь в ~/.bashrc или ~/.zshrc
export OPENAI_API_KEY="sk-твой-ключ-здесь"
```

### Вариант Б: Через файл .env (альтернатива)

1. Создай файл `.env` в папке `backend`:
```
OPENAI_API_KEY=sk-твой-ключ-здесь
```

2. Установи библиотеку python-dotenv (если ещё не установлена):
```bash
pip install python-dotenv
```

3. Код автоматически загрузит переменные из `.env`

## Шаг 3: Проверка работы

Запусти тест чат-бота:
```bash
cd backend
python test_chatbot_local.py --text "Привет, как дела?"
```

Если всё настроено правильно, ты увидишь сообщение:
```
✅ OpenAI клиент инициализирован
```

И получишь умный ответ от GPT вместо простой заглушки.

## Шаг 4: Настройка модели (опционально)

По умолчанию используется `gpt-3.5-turbo` (быстро и недорого).

Если хочешь использовать более мощную модель, можешь изменить код в `llm_core/engine.py`:

```python
from llm_core import LlmEngine, LlmConfig

config = LlmConfig(
    model="gpt-4",  # или "gpt-4-turbo"
    temperature=0.7,
    max_tokens=500
)

llm = LlmEngine(config=config)
```

## Полезная информация

- **Цены**: GPT-3.5-turbo стоит ~$0.0015 за 1K токенов (очень дёшево)
- **Лимиты**: Бесплатный аккаунт имеет лимиты, но их обычно достаточно для тестирования
- **Безопасность**: Никогда не публикуй API ключ в публичных репозиториях!

## Решение проблем

**Ошибка "OPENAI_API_KEY не найден":**
- Проверь, что переменная окружения установлена: `echo $env:OPENAI_API_KEY` (PowerShell)
- Перезапусти терминал после установки переменной

**Ошибка "Invalid API Key":**
- Проверь, что ключ скопирован полностью (начинается с `sk-`)
- Убедись, что нет пробелов в начале/конце ключа

**Ошибка "Insufficient quota":**
- Пополни баланс на https://platform.openai.com/account/billing
