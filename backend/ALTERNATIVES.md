# Альтернативы OpenAI API

Если у тебя проблемы с получением OpenAI API ключа, есть несколько альтернатив:

## Вариант 1: YandexGPT (рекомендуется для РФ)

YandexGPT - это русский аналог от Яндекса, может быть проще получить доступ.

### Преимущества:
- ✅ Работает в России
- ✅ Отличное понимание русского языка
- ✅ Можно попробовать бесплатно

### Как получить:
1. Перейди на https://yandex.cloud/
2. Зарегистрируйся/войди
3. Создай каталог и получи API ключ
4. Документация: https://yandex.cloud/ru/docs/foundation-models/concepts/

### Настройка в коде:
Нужно добавить поддержку YandexGPT API в `llm_core/engine.py`

---

## Вариант 2: Ollama (локально, бесплатно)

Ollama - позволяет запускать LLM модели локально на твоём компьютере, без API ключей.

### Преимущества:
- ✅ Полностью бесплатно
- ✅ Работает офлайн
- ✅ Нет ограничений по запросам
- ✅ Приватность (данные не отправляются в облако)

### Как установить:
1. Скачай Ollama: https://ollama.ai/download
2. Установи и запусти
3. Скачай модель (например, русскую):
   ```bash
   ollama pull llama3.2  # или другая модель
   ```

### Использование:
Ollama работает через локальный API (http://localhost:11434), можно легко подключить в код.

---

## Вариант 3: Hugging Face Inference API

Hugging Face предоставляет бесплатный доступ к многим моделям.

### Преимущества:
- ✅ Бесплатный тариф доступен
- ✅ Много моделей на выбор
- ✅ Хорошая документация

### Как получить:
1. Зарегистрируйся на https://huggingface.co/
2. Получи токен: https://huggingface.co/settings/tokens
3. Используй через API

---

## Вариант 4: Продолжить с заглушкой

Если API не нужен прямо сейчас, можно продолжить разработку с простой заглушкой. 
Она уже умеет отвечать на базовые вопросы, а реальный LLM можно подключить позже.

---

## Что выбрать?

- **Если нужен хороший русский язык и ты в РФ** → YandexGPT
- **Если хочешь бесплатно и офлайн** → Ollama  
- **Если нужны зарубежные модели бесплатно** → Hugging Face
- **Если API не критичен сейчас** → Продолжай с заглушкой

Какой вариант тебя интересует? Могу помочь с настройкой любого из них!
