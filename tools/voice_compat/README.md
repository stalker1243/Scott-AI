# Qwen3-TTS: совместимость с Transformers 5

Локальная сборка `0.1.1+scott.1` сохраняет исходную лицензию Apache-2.0.
Она меняет три Python-файла: интерфейсы Transformers, маски генерации,
контекст Mimi и восстановление непостоянных буферов RoPE после загрузки.
Формула стандартного RoPE перенесена из Transformers 4.57.3 с указанием автора.
Веса и голосовой эталон не меняются. Gradio вынесен в необязательный extra `web`.

`manifest.json` фиксирует SHA256 исходного wheel, патча и изменённых файлов.
Для воспроизведения скачайте указанный там исходный wheel и выполните:

```powershell
py -3.13 tools/build_voice_sdk.py --upstream qwen_tts-0.1.1-py3-none-any.whl --output reports/voice-sdk-rebuild
```

Сборщик работает без сети и установки пакетов, проверяет точный контекст патча
и создаёт wheel с постоянными датами ZIP. Копия исходной лицензии остаётся
в wheel; изменения перечислены в `SCOTT-NOTICE.txt`.

Аудит публичной версии Qwen проверяет её зависимости. Он не заменяет проверку
локального патча: для него дополнительно нужны воспроизводимость и реальные
проверки синтеза, отмены, кеша и перезапуска worker.
