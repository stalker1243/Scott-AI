## Возможности

**Чат и модели.** Отдельные диалоги, история, переименование и очистка,
фотографии, документы, видео и генерация изображений в пределах возможностей
модели. Код отображается отдельными блоками с подсветкой и копированием.
Выбирайте провайдера, модель и свой API Token; интерфейс предупреждает
о неподдерживаемой функции при её выборе.

**Память.** Сведения о пользователе и проектах, завершённые разговоры,
локальный поиск по словам и смыслу, просмотр и удаление записей.

**Голос.** Обращение «Скотт», Whisper, локальный Silero, выбор мужского голоса,
устройств и громкости. Необязательный Scott Voice устанавливается отдельно.
В трее доступны пауза ассистента, тихий режим и уведомления.

**Автоматизация.** Запуск программ, команды окон, напоминания и протоколы
с расписанием. Каталог приложений обновляется автоматически.
В Windows можно нажимать доступные кнопки по названию; на Linux управление
окнами зависит от X11/Wayland. Полной автоматизации любого приложения через
зрение пока нет.

**Оформление.** Classic, Glass, Terminal Pro, светлая и тёмная темы,
акцентные цвета и анимации. Размытие рабочего стола Glass доступно в Windows.

## Windows

Нужны **Windows 10/11 x64** и интернет для первой подготовки и ответов модели.
Скачайте [установщик](https://github.com/stalker1243/Scott-AI/releases/download/v2.1.0/ScottAI-2.1.0-Qt-setup.exe)
и запустите его; права администратора не нужны. Qt и Python входят в пакет.
Библиотеки, Whisper и базовый голос готовятся при первом запуске в отдельном
мастере. Есть прогресс, отмена, повтор и проверка целостности.

Размер установщика не включает скачиваемые библиотеки и модели. CPU требует
нескольких гигабайт; GPU и Scott Voice — больше. Мастер показывает оценку и
проверяет свободное место. NVIDIA/CUDA поддерживается; AMD/ROCm остаётся
экспериментальным, для RX 580 используется CPU.
[Установка и размер](docs/installation.md) · [AMD](docs/amd-support.md).

Для обновления установите новую версию в прежнюю папку. Сохраните резервную
копию `.env` и `backend/data`. Если Scott Voice уже установлен, обновите его
штатной кнопкой в настройках. Старого питомца выключите и включите заново,
чтобы запустить новую кешированную копию.

## Linux — экспериментальный пакет

Доступны **AppImage и tar.gz для x86-64** с собственными Qt и Python.
Данные и окружение Python хранятся отдельно от приложения и сохраняются
при обновлении. Сначала прочитайте [системные зависимости и инструкцию](docs/linux.md).

```bash
# После скачивания AppImage и соответствующего .sha256:
sha256sum -c ScottAI-2.1.0-Qt-linux-x86_64.AppImage.sha256
chmod +x ScottAI-2.1.0-Qt-linux-x86_64.AppImage
./ScottAI-2.1.0-Qt-linux-x86_64.AppImage
# Если FUSE недоступен:
./ScottAI-2.1.0-Qt-linux-x86_64.AppImage --appimage-extract-and-run
```

Для tar.gz: проверьте SHA256, распакуйте архив и запустите `./install.sh`.
Пакет устанавливается в профиль пользователя. При ошибке сохраните журнал
установки или архив из вкладки «Логи».

Свежий пакет проверен в Debian 12: установка, обновление, backend,
AppImage с FUSE и распаковкой; интерфейс X11 и тестовый Wayland/Weston.
Проверки прежних пакетов на Ubuntu, Fedora и Arch описаны отдельно в
[матрице Linux](docs/linux.md). Физические Fedora/Arch, GNOME/KDE, AMD,
звук и несколько мониторов с разным DPI ещё требуют проверки.
Qt-выпуска для macOS пока нет.

## Scott Voice

Базовый локальный голос — Silero. **Scott Voice** — необязательная отдельная
модель с принятым мужским профилем B: сдержанная подача и мягкая цифровая окраска.
Его SDK проверен на Windows с NVIDIA/CUDA; Linux, AMD и CPU для этого движка
пока не проверены. Генерация новых фраз может быть медленной, отдельные огрехи
произношения остаются. Экспериментальные ранняя речь и ускорение выключены
по умолчанию. [Подготовка и ограничения](docs/voice.md).

## Данные и диагностика

Whisper и локальный синтез работают на компьютере. Ответы ИИ и вложения
передаются выбранному провайдеру; облачный резерв Edge TTS получает текст озвучки.
API Token хранится в локальных настройках моделей.

В Windows данные находятся в `backend/data` внутри установки. Linux использует
`~/.local/share/scottai`, `~/.config/ScottAI` и `~/.cache/ScottAI`;
[подробнее о переносе](docs/linux.md#xdg-каталоги-в-текущих-исходниках).
Удаление приложения по умолчанию сохраняет пользовательские данные.

## Разработка

`ScottAI_qt` — C++17/Qt Quick, `backend` — Python/FastAPI, `installer` — сборщики.
Исходники прежних Avalonia и мобильного приложений сохранены в истории Git.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ScottAI_qt/run.ps1
py -3.13 installer/build.py --installer
# Тесты backend запускаются в изолированной копии без рабочих данных и ключей:
py -3.13 backend/run_tests.py
```
