# Scott AI

**Диалоги, память и голосовой помощник для компьютера**

Интерфейс на C++ и Qt Quick. Распознавание Whisper и локальные голоса работают
на вашем компьютере; ответы ИИ — через выбранную модель и ваш API Token.

[Скачать для Windows](https://github.com/stalker1243/Scott-AI/releases/download/v2.0.1/ScottAI-2.0.1-Qt-setup.exe)
· [Скачать для Linux x86-64](https://github.com/stalker1243/Scott-AI/releases/download/v2.0.1/ScottAI-2.0.1-Qt-linux-x86_64.tar.gz)
· [Выпуск 2.0.1](https://github.com/stalker1243/Scott-AI/releases/tag/v2.0.1)
· [Сообщить об ошибке](https://github.com/stalker1243/Scott-AI/issues)

## Что умеет

- **Чат:** отдельные диалоги, история, переименование, очистка, фотографии,
  документы, видео и генерация изображений — в пределах возможностей выбранной модели.
- **Модели:** свои API Token, выбор провайдера и модели, проверка подключения.
  Интерфейс показывает поддерживаемые функции и предупреждает о недоступных.
- **Память:** факты о пользователе и проектах, завершённые разговоры,
  локальный поиск по словам и смыслу, управление записями.
- **Голос:** обращение «Скотт», Whisper, выбор голоса, произношение чисел,
  устройства и громкость. Необязательный мужской Scott Voice с цифровыми вариантами.
- **Действия и протоколы:** запуск программ, системные команды, напоминания,
  последовательности действий, расписания и результаты выполнения.
- **Оформление:** Classic, Glass, Terminal Pro, светлая и тёмная темы,
  акцентный цвет, компактная навигация и анимации окна.
- **Трей:** тихий режим, пауза голосового ассистента, закрепление окна,
  переходы к разделам и уведомления.

Подробности: [чат и вложения](docs/chat.md), [память](docs/memory.md),

## Windows

Скачайте [установщик 2.0.1](https://github.com/stalker1243/Scott-AI/releases/download/v2.0.1/ScottAI-2.0.1-Qt-setup.exe)
и запустите его. Права администратора не нужны. Qt и Python входят в пакет;
библиотеки и модели речи готовятся при первом запуске. Есть отмена и повтор.
Контрольная сумма находится на [странице выпуска](https://github.com/stalker1243/Scott-AI/releases/tag/v2.0.1).

В 2.0.1 улучшена первая подготовка: загрузка моделей показывает
объём, сохраняет недокачанную часть и проверяет целостность перед использованием.
Есть компактная CPU-установка с чатом и голосом, без GPU-ускорения.
Мастер подготовки открывается отдельно; основной интерфейс скрыт до её завершения.
В профиле есть увеличенный редактор фото с перетаскиванием и масштабом.
При ошибке SHA256 не отключайте проверку: воспользуйтесь повтором подготовки.
Подробности — [установка и размер приложения](docs/installation.md).

Нужны Windows 10/11 x64 и интернет для установки и ответов модели.
Микрофон нужен для голосовых команд. Для компактной CPU-подготовки установщик
резервирует 2,5 ГиБ сверх базового пакета; расчёт базовой установки с голосом —
около 1,8 ГиБ. GPU и Scott Voice требуют больше.
NVIDIA/CUDA ускоряет обработку; доступен CPU. Поддержка AMD/ROCm экспериментальная:
[настройка и ограничения](docs/amd-support.md).

## Linux — экспериментальный пакет Qt

Подготовлена сборка для **Linux x86-64** с Qt, backend и собственным Python 3.13.
Установка, backend и запуск X11 проверены на Ubuntu 22.04/24.04, Debian 12/13,
Fedora 44 и Arch. Инструкции, зависимости и границы этих проверок — [Linux](docs/linux.md).

```bash
sha256sum -c ScottAI-2.0.1-Qt-linux-x86_64.tar.gz.sha256
tar -xzf ScottAI-2.0.1-Qt-linux-x86_64.tar.gz
cd ScottAI-2.0.1-Qt-linux-x86_64
./install.sh
~/.local/share/ScottAI/run.sh
```

Сборка и проверка пакета выполняются в
[GitHub Actions](https://github.com/stalker1243/Scott-AI/actions/workflows/linux-qt.yml).
Архив и [SHA256](https://github.com/stalker1243/Scott-AI/releases/download/v2.0.1/ScottAI-2.0.1-Qt-linux-x86_64.tar.gz.sha256)
доступны на странице выпуска без входа в аккаунт.
Проверка на реальном Linux-компьютере с микрофоном ещё предстоит.
Размытие рабочего стола Glass реализовано для Windows; на Linux используется
обычное оформление. Qt-выпуска для macOS пока нет.

## Голос Scott

Базовый локальный синтез использует Silero; доступны резервные голоса.
В настройках можно прослушать голос и выбрать характер подачи.

**Scott Voice** устанавливается отдельно из настроек Qt вместе со своим
Python-окружением. Проверен на Windows с NVIDIA/CUDA и занимает около
7,1 ГиБ. Генерация новых фраз может быть медленной. Раннее начало речи
и ускоренный синтез — отдельные эксперименты, по умолчанию выключены.
Scott Voice на Linux, AMD и CPU ещё не проверен.

## Данные и приватность

- Whisper и локальный синтез выполняются на компьютере. Облачный резервный
  голос передаёт текст озвучки в Edge TTS.
- Вопросы и отправленные вложения передаются выбранному провайдеру ИИ.
- История, вложения и настройки моделей сохраняются в `backend/data`
  внутри папки установки. Настройки моделей содержат введённые API Token.
- Обновляйте приложение в прежнюю папку. Перед обновлением сохраните копию
  `backend/data` и собственного `.env`; автоматического объединения разных
  установок нет.
- По умолчанию удаление приложения сохраняет пользовательские данные.

## Разработка

Основные каталоги: `ScottAI_qt` — C++17/Qt Quick, `backend` — Python/FastAPI,
`installer` — сборщики, `assets/brand` — общие иконки.
Прежние настольный Avalonia и мобильный проекты удалены из текущей ветки;
исторические исходники доступны в теге `v2.0.0`.

```powershell
# Windows: сборка и запуск Qt
powershell -NoProfile -ExecutionPolicy Bypass -File ScottAI_qt/run.ps1
# Установщик Windows: нужны Qt/MinGW, CMake, Ninja и Inno Setup
py -3.13 installer/build.py --installer
# Backend: тесты в копии исходников без рабочих данных и ключей
py -3.13 backend/run_tests.py
```
