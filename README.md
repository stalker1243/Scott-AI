# Мальтруант (Maltruand) 🎙️🤖

**Мальтруант** - голосовой ассистент с искусственным интеллектом для озвучки мультфильмов, фильмов и ответов на вопросы.

Проект для создания мультиязычной системы озвучки видео на языках народов Российской Федерации.

## Структура проекта

- `backend/` - Python сервер с TTS API (FastAPI)
- `app/` - React Native мобильное приложение (будет создано позже)

## Быстрый старт

### Backend (Python сервер)

1. Убедитесь, что у вас установлен Python 3.10+ (рекомендуется 3.11 или 3.12)
   - ⚠️ **Важно**: Python 3.13 пока не поддерживает некоторые TTS библиотеки (Coqui TTS требует <3.12)

2. Установите зависимости:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. Запустите сервер:
   ```bash
   python main.py
   ```

4. Сервер будет доступен по адресу: `http://127.0.0.1:8000`
   - Документация API: `http://127.0.0.1:8000/docs`
   - Проверка здоровья: `http://127.0.0.1:8000/health`

## API Endpoints

### `GET /health`
Проверка работоспособности сервера.

**Ответ:**
```json
{"status": "ok"}
```

### `POST /synthesize`
Генерация речи из текста (пока заглушка).

**Запрос:**
```json
{
  "text": "Привет, мир!",
  "language": "ru",
  "speaker": null
}
```

**Ответ:** WAV файл с аудио

## Локальное тестирование чат-бота

Теперь можно протестировать всю систему локально без сервера!

### Тест с текстовым вопросом:

```bash
cd backend
python test_chatbot_local.py --text "Привет, как дела?"
```

Или через bat-файл:
```bash
cd backend
test_chatbot.bat --text "Привет, как дела?"
```

### Тест с аудиофайлом:

```bash
python test_chatbot_local.py --audio "question.wav" --out "answer.wav"
```

### Что происходит:

1. **ASR** (если указан `--audio`) - распознаёт речь из аудиофайла
2. **LLM** - обрабатывает вопрос и генерирует ответ
3. **TTS** - озвучивает ответ и сохраняет в WAV файл

### Настройка LLM:

По умолчанию используется простая заглушка с базовыми правилами. Для подключения OpenAI API:

1. Установи переменную окружения:
   ```bash
   set OPENAI_API_KEY=your_api_key_here
   ```

2. Или измените код в `llm_core/engine.py` для использования другого провайдера.

## LLM (обработка вопросов) ✅

Система поддерживает несколько вариантов LLM:

### Вариант 1: Ollama (рекомендуется) ✅

**Ollama работает!** Локально, бесплатно, без API ключей.

**Как использовать:**
1. Установи Ollama: https://ollama.ai/download
2. Скачай модель: `ollama run qwen2.5:7b`
3. Используй в коде:
   ```python
   from llm_core import LlmEngine, LlmConfig
   config = LlmConfig(provider="ollama", model="qwen2.5:7b")
   llm = LlmEngine(config=config)
   ```

📖 **Подробная инструкция**: См. `backend/SETUP_OLLAMA.md`

### Другие варианты:

- **Заглушка** - работает по умолчанию (базовые ответы)
- **YandexGPT** - работает в РФ (см. `backend/ALTERNATIVES.md`)
- **OpenAI API** - если доступен (см. `backend/SETUP_OPENAI.md`)

### Что работает:

## Примечания

- Для Python 3.13 может потребоваться использовать альтернативные TTS библиотеки (например, `edge-tts` или `gTTS`)
- Для работы с видео потребуется установить `ffmpeg`
- OpenAI API ключ опционален — без него система работает с простой заглушкой
