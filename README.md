## 2.2.0 — интерфейс и надёжность

[Как пользоваться ScottAI](docs/guide.md) · [Изменения 2.2.0](docs/release-notes-2.2.0.md)

Scott Voice — единственный локальный голос приложения, с профилем Scott (B)
по умолчанию. Остальные голоса и автоматическое переключение на них убраны.
Первая подготовка больше не скачивает Silero и его речевые зависимости.
Scott Voice устанавливается на **главном экране** или в **Настройки → Голос**; пока поддерживается
Windows x64 с NVIDIA CUDA. До подготовки компонента доступны чат и распознавание.
Выпуск включает адаптивное окно с плавными переходами, удобный чат и меню питомца
с мини-чатом и микрофоном. Протоколы отключены для отдельной доработки.

Добавлено восстановление после сбоев: мастер первого запуска дожидается
подключения backend, а повтор запуска не начнёт скачивать библиотеки заново.
Лаунчер попробует восстановить собственный завершившийся backend до трёх раз.
Чат сохраняет идентификатор запроса: потерянный ответ можно получить из истории,
не выполняя действие повторно. Если результат действия неизвестен, приложение
сообщит об этом. [Запуск и восстановление](docs/reliability.md).

Для поиска задержек добавлена разбивка подготовки, распознавания и голоса
по этапам. Замеры входят в архив логов; техническую сводку можно получить
без текста команд и API Token. [Как прочитать замеры](docs/performance.md#собрать-сведения-о-проблеме).

При запуске backend готовится распознавание. Scott Voice загружается по явному
запросу из лаунчера; генерация служебных фраз больше не занимает его при старте.
Готовые записи кеша сохраняются.

Лаунчер больше не восстанавливает старое закрепление поверх других приложений:
его можно включить через трей на текущий сеанс. Меню и мини-чат питомца
выбирают свободное место рядом с ним. [Поведение окон](docs/interface.md#поведение-окон-подготовлено-после-211).

Раздел голоса упрощён: установка Scott Voice, проверка, прослушивание,
громкость и аудиоустройства. Технические переключатели убраны; сохранённое
звучание применяется при запуске. Распознавание работает через Whisper.

## 2.1.1 — «Работа над скоростью»

Текст ответа появляется по мере генерации в основном и мини-чате. Голос может
начать с первой законченной фразы, пока модель готовит продолжение. Во время
запроса кнопка отправки останавливает ожидание; черновик и вложения сохраняются.

Независимые диалоги обрабатываются параллельно в пределах лимитов backend.
Обновление каталога моделей выполняется в фоне, а память реже читает настройки.
Для поиска задержек отдельно измеряются первый текст, готовность звука и полное
завершение запроса. Скорость самой модели и Scott Voice зависит от провайдера
и компьютера; холодная подготовка голоса всё ещё может занимать время.

## Больше пространства для общения

Интерфейс стал компактнее: «Обзор» показывает состояние помощника, история чата
открывается в боковой панели, а оформление собрано в «Персонализации». Выбирайте
Classic, Glass или Terminal Pro, тему и акцентный цвет; переключайте язык без
перезапуска. Текст, вложения и блоки кода удобно помещаются даже в небольшом окне.

И ещё **маленький милый сюрприз на вашем экране**: Скотт Младший.
Он следит глазами, выражает эмоции и реагирует на ваши действия. Его можно
передвинуть, изменить размер и открыть мини-чат прямо над ним — спросить что-то
или попросить помочь без открытия основного окна. В меню из трёх значков можно
скрыть питомца, открыть мини-чат или включить микрофон. Пока вы говорите,
Скотт создаёт светящийся атом в руках. Включение и оформление питомца
находятся в «Персонализации»; скрыть его можно отдельно от приложения.

## Возможности

**Чат и модели.** Отдельные диалоги, история, переименование и очистка,
фотографии, документы, видео и генерация изображений в пределах возможностей
модели. Код отображается отдельными блоками с подсветкой и копированием.
Выбирайте провайдера, модель и свой API Token; интерфейс предупреждает
о неподдерживаемой функции при её выборе.

**Память.** Сведения о пользователе и проектах, завершённые разговоры,
локальный поиск по словам и смыслу, просмотр и удаление записей.

**Голос.** Обращение «Скотт», Whisper, локальный Scott Voice, выбор
устройств и громкости. Компонент Scott Voice устанавливается отдельно.
В трее доступны пауза ассистента, тихий режим и уведомления.

**Автоматизация.** Запуск программ, команды окон и напоминания. Каталог приложений обновляется автоматически.
В Windows можно нажимать доступные кнопки по названию; на Linux управление
окнами зависит от X11/Wayland. Полной автоматизации любого приложения через
зрение пока нет.

**Оформление.** Classic, Glass, Terminal Pro, светлая и тёмная темы,
акцентные цвета и анимации. Размытие рабочего стола Glass доступно в Windows.

## Windows

Нужны **Windows 10/11 x64** и интернет для первой подготовки и ответов модели.
Скачайте [установщик](https://github.com/stalker1243/Scott-AI/releases/download/v2.2.0/ScottAI-2.2.0-Qt-setup.exe)
и запустите его; права администратора не нужны. Qt и Python входят в пакет.
Библиотеки и распознавание готовятся при первом запуске в отдельном мастере.
Scott Voice устанавливается отдельно. Есть прогресс, отмена, повтор и проверка целостности.

Размер установщика не включает скачиваемые библиотеки и модели. CPU требует
нескольких гигабайт; GPU и Scott Voice — больше. Мастер показывает оценку и
проверяет свободное место. NVIDIA/CUDA поддерживается; AMD/ROCm остаётся
экспериментальным, для RX 580 используется CPU.
[Установка и размер](docs/installation.md) · [AMD](docs/amd-support.md).

Для обновления установите новую версию в прежнюю папку. Сохраните резервную
копию `.env` и `backend/data`. Если Scott Voice уже установлен, обновите его
штатной кнопкой в настройках. Старого питомца выключите и включите заново,
чтобы запустить новую кешированную копию.

## Linux — beta

Доступны **AppImage и tar.gz для x86-64** с собственными Qt и Python.
Данные и окружение Python хранятся отдельно от приложения и сохраняются
при обновлении. Сначала прочитайте [системные зависимости и инструкцию](docs/linux.md).

```bash
# После скачивания AppImage и соответствующего .sha256:
sha256sum -c ScottAI-2.2.0-Qt-linux-x86_64.AppImage.sha256
chmod +x ScottAI-2.2.0-Qt-linux-x86_64.AppImage
./ScottAI-2.2.0-Qt-linux-x86_64.AppImage
# Если FUSE недоступен:
./ScottAI-2.2.0-Qt-linux-x86_64.AppImage --appimage-extract-and-run
```

Для tar.gz: проверьте SHA256, распакуйте архив и запустите `./install.sh`.
Пакет устанавливается в профиль пользователя. При ошибке сохраните журнал
установки или архив из вкладки «Логи».

Пакет проходит автоматические проверки установки, обновления, backend и
распаковки AppImage. Сведения о дистрибутивах и проверках — в
[матрице Linux](docs/linux.md). Физические GNOME/KDE, AMD, микрофон, звук
и несколько мониторов с разным DPI ещё требуют проверки. Синтез Scott Voice
на Linux пока не поддерживается.
Qt-выпуска для macOS пока нет.

## Scott Voice

Начиная с 2.2.0 единственный голос — **Scott Voice**, отдельная
модель с принятым мужским профилем B: сдержанная подача и мягкая цифровая окраска.
Его SDK проверен на Windows с NVIDIA/CUDA; Linux, AMD и CPU для этого движка
пока не проверены. Генерация новых фраз может быть медленной, отдельные огрехи
произношения остаются. [Подготовка и ограничения](docs/voice.md).

## Данные и диагностика

Whisper и локальный синтез работают на компьютере. Ответы ИИ и вложения
передаются выбранному провайдеру. В 2.2.0 облачный резерв Edge TTS убран;
прежние версии могут использовать его для озвучки.
API Token хранится в локальных настройках моделей.

В Windows данные находятся в `backend/data` внутри установки. Linux использует
`~/.local/share/scottai`, `~/.config/ScottAI` и `~/.cache/ScottAI`;
[подробнее о переносе](docs/linux.md#xdg-каталоги-в-текущих-исходниках).
Удаление приложения по умолчанию сохраняет пользовательские данные.

## Разработка

`ScottAI_qt` — C++17/Qt Quick, `backend` — Python/FastAPI, `installer` — сборщики.
Исходники прежних Avalonia и мобильного приложений сохранены в истории Git.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ScottAI_qt/run.ps1
py -3.13 installer/build.py --installer
# Тесты backend запускаются в изолированной копии без рабочих данных и ключей:
py -3.13 backend/run_tests.py
```
