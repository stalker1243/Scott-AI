# Scott AI

**Голосовой ассистент, который слушает и управляет компьютером**

Распознавание и синтез речи работают на вашей видеокарте, локально.
Скажите «Скотт» — и он вас услышит.

</div>

## Установка

**Версия 2.0 — крупное обновление для Windows x64.** Новый интерфейс Qt,
диалоги с вложениями, настройки моделей, постоянная память и Scott Voice.
[Что изменилось](docs/release-notes-2.0.0.md).

**Windows.** Скачайте установщик со страницы [Releases](../../releases) и
запустите. Права администратора не нужны.

Для нового интерфейса Qt сборщик `python installer/build.py --installer`
создаёт `installer/release/ScottAI-<версия>-Qt-setup.exe`. Он включает Qt и
Python; при первом запуске окно подготовки показывает загрузку библиотек
и моделей речи. Вариант Avalonia собирается с `--launcher avalonia`.

**Linux** (пробная поддержка, см. ниже). Скачайте архив
`ScottAI-…-linux-x64.tar.gz` оттуда же:

Готовые Linux/macOS-дистрибутивы пока относятся к версии 1.2; выпуск 2.0
подготовлен для Windows.

```bash
tar -xzf ScottAI-*-linux-x64.tar.gz
cd ScottAI-*/
./install.sh
```

Ставится в папку пользователя, без sudo. Понадобятся `python3` (3.10+),
`python3-venv` и `libportaudio2` для микрофона — установщик проверит и скажет,
чего не хватает.

**macOS** (пробная поддержка, см. ниже). Скачайте образ
`ScottAI-…-macos-arm64.dmg` (для процессоров Apple) или `…-macos-x86_64.dmg`
(для прежних Mac на Intel) и перетащите программу в «Программы».

При первом запуске система скажет, что программа «повреждена». Это не
повреждение: у сборки нет подписи Apple, для которой нужен платный счёт
разработчика. Снимается одной командой:

```bash
xattr -dr com.apple.quarantine /Applications/ScottAI.app
```

Понадобится Python 3.13 — `brew install python@3.13`, если его ещё нет.

При первом запуске Scott докачает то, что зависит от вашего железа: библиотеки
распознавания речи и модели. Это занимает 5–15 минут, на экране видно, сколько
осталось. Дальше интернет нужен только для ответов ИИ.

**Что понадобится**

| | |
|---|---|
| Система | Windows 10 или новее; Linux и macOS 11+ — пробно |
| Место | около 5 ГБ |
| Видеокарта | NVIDIA CUDA или совместимая AMD ROCm — для ускорения; CPU тоже поддерживается |
| Микрофон | для голосовых команд |
| Ключ ИИ | бесплатный ключ Groq, вводится в Настройках |

### Видеокарты AMD

Добавлена экспериментальная поддержка AMD ROCm/HIP для Whisper и Silero на
Windows и Linux. В Qt: **Настройки → Обработка → AMD**. Нужны совместимые
карта, драйвер и сборка PyTorch; установка и диагностика описаны в
[инструкции AMD](docs/amd-support.md). При ошибке GPU голосовые модели могут
повторить обработку на CPU. Проверка на физической AMD-карте ещё предстоит.

## Что умеет

**Слышит по имени.** Микрофон открыт постоянно, но команда выполняется только
после обращения: «Скотт, открой браузер». Всё остальное он пропускает мимо.

**Управляет компьютером.** Открывает программы и сайты, показывает загрузку
процессора и список процессов, меняет громкость и яркость, работает с файлами
и папками.

**Помнит о делах.** «Напомни в 18:00 зайти в Discord» — разберёт живую речь и
напомнит вовремя.

**Помнит разговоры.** Факты о вас и проектах и завершённые диалоги сохраняются
между запусками. Scott подбирает сведения по словам и по смыслу, выполняя
поиск локально. Во вкладке
«Память» можно посмотреть записи, отключить автозапоминание и очистить историю.
[Как работает память](docs/memory.md).

**Обсуждает вложения и создаёт изображения.** В Qt можно прикрепить фото или
документ, перетащить файлы в диалог, сохранить результат генерации и вернуться
к переписке после перезапуска. Диалоги можно переименовывать, очищать и удалять.
Значки «Файлы», «Фото», «Видео», «Генерация» показывают возможности выбранной
модели. Доступ зависит от модели и вашего API Token.
[Чат, форматы и ограничения](docs/chat.md).

**Пишет и запускает код.** «Напиши программу на C, которая выводит Hello,
World!» — проверит, чем эта машина умеет собирать, напишет, покажет код с
кнопкой «Копировать» и по отдельной просьбе соберёт и запустит.

**Отвечает голосом.** Говорит вслух, а не только пишет: числа проговаривает
словами, значки и блоки кода не зачитывает, ударения ставит по словарю.
Голос сохраняется после перезапуска. «Выбери голос Светланы», «говори тише»,
«громкость голоса пятьдесят пять процентов», «выключи озвучку» меняют настройки
речи Scott. «Покажи голоса» перечисляет доступные имена; выбрать можно любой
голос из каталога.

В Qt: **Настройки → Голос → Установить Scott Voice**. Отдельный мужской
голос с цифровыми вариантами устанавливается вместе со своим Python;
доступны отмена, повтор и проверка готовности. Установка занимает около
7,1 ГиБ; для этого движка пока проверена NVIDIA/CUDA.
В настройках Scott Voice есть экспериментальное **Раннее начало речи**:
звук поступает по мере синтеза. Режим по умолчанию выключен; между блоками
пока возможны паузы.
Есть и **Ускоренный синтез** — отдельный экспериментальный режим Scott Voice.
Он может менять звучание и по умолчанию выключен.
При раннем начале речи можно выбрать **Запас звука**: сразу, 2 или 4 секунды,
либо вся фраза. Накопление уменьшает ожидание между блоками и откладывает начало.
Блоки одного ответа используют общий выходной поток звука; отмена прерывает
его и отбрасывает остаток старого ответа.
В раннем режиме следующая часть готовится во время текущей озвучки;
подготовка ограничена одной частью вперёд. Паузы зависят от скорости модели.
Кнопка **Подготовить к речи** заранее загружает модель Scott Voice и опору
голоса. Есть отмена и **Освободить модель**; после двух минут простоя память
освобождается автоматически. Подготовка запускается вручную.

Для спокойной мужской подачи в Qt доступны Евгений и характер «Спокойный —
мягкий и чёткий». В настройках можно прослушать пробную фразу с числами и
техническими терминами. [Голос и произношение](docs/voice.md).

Whisper использует общий путь для микрофона и аудиофайлов, ограниченное усиление
тихой речи и проверку тишины. Для более точного распознавания на подходящей
видеокарте можно выбрать `turbo`. [Настройка и измерения](docs/recognition.md).

**Работает в фоне.** Закрытое окно не выключает Scott — он остаётся в области
уведомлений и продолжает слышать обращение.

## Приватность

Распознавание (Whisper) и локальные голоса (Silero) работают на компьютере.
При выборе облачного голоса текст озвучки отправляется в Edge TTS.
Текст вопросов и отправленные вложения передаются выбранному провайдеру ИИ.
История чата и вложения сохраняются локально; удаление диалога удаляет его
файлы и записи из памяти разговоров. Отдельно сохранённые факты доступны
во вкладке «Память».

История и настройки backend хранятся в `backend/data` внутри папки установки.
Обновляйте приложение в эту же папку. При удалении приложения данные
сохраняются по умолчанию; их удаление выбирается отдельно. Тихое удаление
сохраняет данные. Настройки моделей содержат введённые API Token.

Сервер ассистента слушает исключительно localhost — из локальной сети к нему
не подключиться. Операции, способные навредить (выключение, удаление файлов,
команды оболочки), закрыты токеном.

## Если что-то не работает

Запуск из исходников, изолированные тесты, эксперимент Scott Voice и
очистка временных файлов описаны в [инструкции для разработки](docs/development.md).

Разработчики могут запустить тесты backend в отдельной временной копии исходников:

```powershell
py -3.13 backend/run_tests.py
py -3.13 backend/run_tests.py tests/test_chats.py -q
```

Личная история, модели и ключи API в эту копию не переносятся. По умолчанию
запускаются проверки без интеграционных и медленных тестов.

Голосовой путь можно проверить без микрофона и выполнения команд:

```powershell
py -3.13 backend/check_voice.py
py -3.13 backend/check_voice.py --suite --all-voices
```

Проверка создаёт запись через Silero, распознаёт её через Whisper и показывает,
какую команду понял Scott. Результат и WAV сохраняются в `reports/voice-check`.
Для проверки нужны установленные модели Silero и Whisper.
`--suite` проверяет корпус команд, параметры действий, 12 фраз управления
озвучкой и пустой результат на тишине и тихом шуме;
`--all-voices` добавляет короткую проверку остальных локальных голосов.
Сводка сохраняется в `reports/voice-check/suite.json`. Команды не выполняются,
микрофон и воспроизведение не включаются.

Результаты последней проверки и известные ошибки распознавания:
[отчёт по backend](docs/backend-audit-2026-10-05-pass2.md).

Откройте вкладку **«Логи»** → **«Собрать отчёт»**: Scott сложит в архив свои
логи, состояние компьютера и настройки. Ключи и токены оттуда вырезаются —
архив можно показывать посторонним.

Дальше два пути, оба открываются кнопкой прямо из Scott:

* **«Сообщить на GitHub»** — страница обращения с уже заполненным описанием;
  остаётся перетащить туда файл архива. Ответ виден всем: вдруг у кого-то то же
  самое.
* **«Написать в Telegram»** — откроется канал и папка с архивом; напишите в
  комментариях и приложите файл. Аккаунт GitHub для этого не нужен.

## Насчёт Linux и macOS

Поддержка пробная и честно помечена как таковая: код к ней подготовлен, но
вживую Scott работал только на Windows.

**На Linux** громкость, яркость, питание и запуск программ идут через
привычные средства: `wpctl`/`pactl`/`amixer`, `brightnessctl`, `systemctl`,
`.desktop`-файлы.

**На macOS** тем же занимается `osascript`, программы ищутся среди
установленных приложений и через Spotlight, а запускаются командой `open`.
Работает это чуть иначе, чем на Windows, и о двух отличиях стоит знать
заранее:

* Распознавание речи считает процессор — библиотека, которая этим занимается,
  графику Apple не поддерживает. Синтез, наоборот, идёт на ней.
* Система спросит доступ к микрофону и к управлению другими программами. Без
  первого Scott не услышит обращение по имени, без второго не сможет менять
  громкость и открывать приложения.

Сборка под macOS собирается и проверяется на настоящей macOS при каждом
изменении — но проверки это не то же самое, что живая работа за компьютером.

Если вы запустите Scott у себя и что-то пойдёт не так,
[расскажите](../../issues): это ровно та обратная связь, которой сейчас не
хватает.
