## 📱 API ENDPOINTS (Все работают)

```bash
# Вопрос
POST /ask
{
  "question": "Что ты умеешь?"
}
→ {answer, type, quiet_mode}

# Озвучивание
POST /text_to_speech
{
  "text": "Привет мир"
}
→ Audio WAV/MP3

# Распознавание
POST /speech_to_text
{
  "audio": <binary>
}
→ {text, confidence}

# Команда ОС
POST /command
{
  "command": "открой калькулятор"
}
→ {result, success}

# Статус
GET /ai/status → {components, status}
GET /health → {status, timestamp}
```

## 🎬 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### Python
```python
import requests

# Спросить
response = requests.post('http://localhost:8000/ask', 
    json={'question': 'Что ты умеешь?'})
print(response.json()['data']['answer'])

# Озвучить
response = requests.post('http://localhost:8000/text_to_speech',
    json={'text': 'Привет!'})
# Сохранить audio
```

### JavaScript (API Client)
```javascript
// Спросить
const response = await fetch('http://localhost:8000/ask', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({question: userInput})
});
const {data} = await response.json();

// Озвучить ответ
if (config.voice_enabled) {
    const audioResponse = await fetch('http://localhost:8000/text_to_speech', {
        method: 'POST',
        body: JSON.stringify({text: data.answer})
    });
    const audio = new Audio(URL.createObjectURL(await audioResponse.blob()));
    audio.play();
}
```
