# Эталон Scott Voice

`reference/scott-reference.wav` — принятый пользователем синтетический мужской
тембр «Чуть строгий». Это точная копия защищённого эталона из локального
отчёта; метаданные и текст эталонной фразы находятся в `reference.json`.

SHA256: `78f48237579b5323bd5e738095fa17f4c30f1f76d8976e66ef128b850eea42f3`.

Эталон используется для отдельной установки Scott Voice. Сборщик проверяет
его контрольную сумму и копирует запись без перегенерации. Рабочая история,
настройки и ключи в эти ресурсы не входят.

Голос создан локально с Qwen3-TTS VoiceDesign и принят на слух. Веса и SDK
устанавливаются отдельно. Источники и лицензия Apache-2.0:
[Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS),
[Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base).
